本目录是 coding-agent 的运行时内核，按职责拆分为多个子模块并通过 `core/index.ts` 统一再导出：
- 编排层：`agent-session-runtime.ts` / `agent-session-services.ts` / `agent-session.ts` 构成会话创建→服务装配→生命周期调度的主链路，所有运行模式（CLI/TUI/Headless）均经此入口。
- 能力层：`model_provider_registry`（模型注册与调度）、`tools_and_renderers`（内置工具与 TUI 渲染）、`extensions_system`（插件加载与事件分发）、`compaction`（上下文压缩）、`export_html`（HTML 导出）等作为可插拔能力被会话运行时消费。
- 基础设施层：`settings_config`、`auth_trust_credentials`、`runtime_infrastructure`、`mcp_radius_integration`、`ui_shell_features`、`sdk_and_api` 提供跨子模块共享的配置、凭据、进程/HTTP、MCP/Radius、Shell UI 与 SDK 契约。
- 子模块之间通过 TypeScript 类型与事件总线（`event-bus.ts`）解耦；扩展系统通过 `defineTool` / `ExtensionAPI` 将外部工具注入到同一工具注册表，使内置工具与扩展工具在会话运行时中无差别调用。
