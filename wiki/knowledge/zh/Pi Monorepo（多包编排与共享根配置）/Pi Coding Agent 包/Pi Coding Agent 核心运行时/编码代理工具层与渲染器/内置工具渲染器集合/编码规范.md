- 每个工具渲染器文件在顶部注释说明“渲染器与实现分离以避免加载执行路径和 typebox schema”，并在该文件内导出 `renderCall`/`renderResult` 组成的 `Pick<ToolDefinition, ...>` 对象。
- 渲染器通过 `context.lastComponent` 复用上一次渲染返回的 TUI 组件（如 `Text`/`Container`），不存在时再新建，避免重复创建节点。
- 对长输出采用折叠展示：非 expanded 模式下使用 `VisualLinePreview` 或固定行数截断，并以 `keyHint('app.tools.expand', 'to expand')` 提示用户展开。
- 工具参数兼容旧字段名与新字段名（如 `file_path` 与 `path`、`offset`/`limit` 与 `oldText`/`newText`），通过 `str()` 与条件判断做降级兼容。
- 结果中的截断信息统一从 `result.details.truncation` 读取，并使用 `formatSize(DEFAULT_MAX_BYTES)` 等公共格式化函数输出警告文本。
