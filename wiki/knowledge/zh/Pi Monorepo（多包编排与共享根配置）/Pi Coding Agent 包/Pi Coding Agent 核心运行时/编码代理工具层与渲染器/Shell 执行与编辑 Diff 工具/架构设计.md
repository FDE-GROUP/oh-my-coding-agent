模块由两类独立子域组成：
- Shell 执行工具（bash.ts、powershell.ts）：bash.ts 定义核心抽象 `BashOperations`（exec 接口）、`createLocalShellOperations`（基于 Node `child_process.spawn` 的本地实现，含超时、进程树清理、detached pid 跟踪、PI_* 会话环境变量注入、`OutputAccumulator` 流式输出与截断），并通过 `createShellToolDefinition` + `ShellToolConfig` 工厂复用出 `bash` 与 `powershell` 两个 ToolDefinition；PowerShell 仅通过包装 exec 前缀 UTF8 编码指令复用该实现。
- 编辑 Diff 工具（edit-diff.ts）：纯函数库，依赖 `diff` 包，提供行尾检测/归一化、模糊匹配（normalizeForFuzzyMatch）、`applyEditsToNormalizedContent`（批量 edit 校验、去重、重叠检查、按行保留未改动块）、统一补丁与带行号 diff 渲染，并暴露 `computeEditsDiff` / `computeEditDiff` 供 TUI 预览调用。
依赖方向单向：shell 工具依赖 utils/shell、utils/child-process、./output-accumulator、./truncate、./renderers/bash；edit-diff 仅依赖 fs、diff 和 ./path-utils，两者互不耦合。
