本模块包含三个并列的 ToolDefinition 实现：find.ts（基于 fd 的 glob 文件搜索）、grep.ts（基于 ripgrep 的内容搜索）、ls.ts（基于 fs 的目录列举）。每个文件遵循相同分层：
- 参数 schema 通过 TypeBox `Type.Object` 声明，并导出对应的 `Static<typeof XSchema>` 类型。
- 通过 `createXxxToolDefinition(cwd, options)` 返回标准 `ToolDefinition`，再由 `wrapToolDefinition` 包装为 `TypeBoxAgentTool`。
- 对外暴露 `createXxxTool` 工厂函数，便于在扩展中注入自定义 cwd。
- 通过 `operations` 选项 + 对应 `FindOperations`/`GrepOperations`/`LsOperations` 接口实现后端可插拔（默认使用本地 fd/ripgrep/fs），以便未来扩展到 SSH 等远程系统。
- 渲染逻辑解耦到同级 `renderers/find.ts`、`renderers/grep.ts`、`renderers/ls.ts`，通过展开运算符合并进 ToolDefinition。
- 输出统一经 `truncate.ts` 的 `truncateHead` 按字节上限 `DEFAULT_MAX_BYTES` 截断，并通过 `details.truncation` / `resultLimitReached` / `matchLimitReached` / `entryLimitReached` 等字段向调用方反馈截断状态。
- 依赖方向单向向外：本模块依赖 `path-utils`、`tool-definition-wrapper`、`truncate`、`extensions/types` 和外部工具管理器 `ensureTool`，不反向依赖上层框架。
