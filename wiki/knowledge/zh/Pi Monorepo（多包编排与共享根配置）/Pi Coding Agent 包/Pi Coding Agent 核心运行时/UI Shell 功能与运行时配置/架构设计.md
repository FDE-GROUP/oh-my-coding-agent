本模块是 coding-agent 的 UI shell 能力集合，按职责拆分为若干独立文件，彼此通过共享类型和工具函数耦合：
- 交互入口：`slash-commands.ts` 定义 `SlashCommandInfo` / `BuiltinSlashCommand` 及内置命令常量；`keybindings.ts` 基于 `@earendil-works/pi-tui` 的 `KeybindingsManager` 扩展应用级快捷键，并通过 `KEYBINDING_NAME_MIGRATIONS` 做旧键名迁移。
- 配置与模式：`keybindings-schema.ts` 用 TypeBox 动态生成 `keybindings.json` 的 JSON Schema（遍历 `KEYBINDINGS` 导出属性）。
- 提示工程：`system-prompt.ts` 将 tools/skills/contextFiles/cwd 等选项规范化后组装成带 XML 分节（`preamble`/`tools`/`rules`/`docs`/`project_context`/`skills`/`cwd`）的结构化 system prompt，并提供 diff 补丁；`prompt-templates.ts` 扫描全局/项目/显式路径下的 `.md` 模板，支持 frontmatter 与 bash 风格参数替换；`skills.ts` 扫描 `SKILL.md` 并输出 Agent Skills 规范的 XML 列表供 system prompt 引用。
- 消息协议：`messages.ts` 通过声明合并向 `pi-agent-core` 的 `CustomAgentMessages` 注入 `bashExecution`/`custom`/`branchSummary`/`compactionSummary` 四种角色，并提供 `convertToLlm` 转换器。
- 诊断与上报：`bug-report.ts` 收集环境/模型/provider/extension/settings 元数据（对 URL、敏感 key 做 redact），可调用会话模型生成 Markdown 摘要；`bug-report-upload.ts` 将 bundle 以 multipart/form-data 上传至 Radius `/v1/bug-reports`；`crash-log.ts` 在 `agentDir/crashes.json` 中持久化未捕获异常，并匹配堆栈中的 extension 来源。
- 状态展示：`footer-data-provider.ts` 维护 Git 分支缓存、extension status 与 provider 计数，通过 `fs.watch` + reftable 目录监听 HEAD/reftable 变更，并在 WSL/mounted path 场景回退到轮询。
依赖方向单向向外：本模块消费 `config.ts`、`utils/*`、`@earendil-works/pi-*` 包，被上层 session/extension 框架消费，不反向依赖它们。
