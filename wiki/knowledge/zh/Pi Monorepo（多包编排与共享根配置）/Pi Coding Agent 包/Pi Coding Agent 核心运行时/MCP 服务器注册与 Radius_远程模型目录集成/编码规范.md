- 对外暴露的配置类型通过接口交叉组合（extends）pi-mcp 的共享字段，再叠加 pi 自有字段，以保持与底层库解耦。
- 配置校验采用「先解析别名再委托第三方校验」的两阶段模式：先用 `resolveExposureAliases` 把旧值映射为新值，再调用 `validateMcpServerFields` 做结构校验。
- 工具名匹配统一通过 `createToolNameMatcher` 或内联的 `toolPatternRegExp` 将含 `*` 的模式编译为正则，精确名称优先于模式匹配。
- 可插拔能力以装饰器工厂形式提供（如 `withRemoteCatalog`、`withPersonalizedCatalog`），返回一个实现了相同 `Provider` 接口的对象，保留原方法并增强 `refreshModels`。
- 网络访问统一走 `fetchWithRetry`，并通过 `context.publish({ update, persist })` 同步内存状态与持久化存储，避免直接读写磁盘。
