模块以 `index.ts` 作为对外出口，暴露三类运行入口与共享类型：
- `interactive/interactive-mode.ts`：基于 `@earendil-works/pi-tui` 的完整 TUI 前端，包含 `components/`（消息渲染、选择器、编辑器等 UI 组件）、`theme/`（dark/light/system 主题及 Token 体系）、`chat-viewport.ts`、`tui-renderer.ts` 等，是唯一的富交互实现。
- `rpc/rpc-mode.ts` + `rpc/rpc-client.ts` + `rpc/jsonl.ts` + `rpc/rpc-types.ts`：进程内 RPC 服务端与子进程 RPC 客户端成对出现；服务端通过 stdin/stdout 的 JSONL 协议接收命令并流式回传事件，同时把扩展 UI 能力桥接为 `extension_ui_request` 事件；客户端 `RpcClient` 用 `spawn('node', ['dist/cli.js', '--mode', 'rpc'])` 启动独立进程并通过 `attachJsonlLineReader` 解析响应。
- `print-mode.ts`：一次性脚本模式，支持 `text`（仅最终文本）和 `json`（全量事件流）两种输出。

依赖方向单向向下：所有模式都消费 `AgentSessionRuntime` 与 `AgentSession`，不反向依赖彼此；`json-event.ts` 定义跨模式的 `JsonAgentSessionEvent` 序列化契约，RPC 与 print 共用同一转换器以消除 streaming 累积快照。IPC 协议在 `rpc-types.ts` 中集中声明，命令分发在 `handleCommand` 的大 `switch` 中按 Prompting / State / Model / Thinking / Queue Modes / Compaction / Retry / Bash / Session / Messages / Commands 分区组织。
