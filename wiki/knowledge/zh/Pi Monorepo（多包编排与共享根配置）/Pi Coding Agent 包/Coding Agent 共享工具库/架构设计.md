本模块是 `packages/coding-agent/src/utils/` 下的纯工具集合，无入口点，被上层业务代码按需 import；内部按职责横向切分为若干独立子域：
- 进程与 Shell：`child-process.ts`（封装 `cross-spawn` 的 spawn/spawnSync + `waitForChildProcess` 优雅等待）、`shell.ts`（bash/pwsh 解析、`getShellEnv` 注入 binDir、进程树清理）、`git.ts`、`wsl.ts`。
- 网络与下载：`management-http.ts`（带状态码白名单的重试 fetch）、`tools-manager.ts`（从 GitHub Releases 自动下载 fd/rg 二进制并解压到 `getBinDir()`）、`version-check.ts`、`windows-self-update.ts`。
- 图像处理：`image-resize.ts`（对外 API，通过 `node:worker_threads` 在 worker 中运行 Photon WASM，Bun 编译产物下回退到进程内）、`image-resize-core.ts`（核心缩放算法，PNG/JPEG 多候选择优）、`image-resize-worker.ts`（worker 端实现）、`photon.ts`（WASM 加载）、`exif-orientation.ts`、`image-convert.ts`、`image-process.ts`。
- 剪贴板：`clipboard.ts`（统一接口）+ `clipboard-command.ts`（命令行后端）+ `clipboard-image.ts`（图片编解码）。
- 文件系统与文本：`fs-watch.ts`、`output-files.ts`、`zip.ts`、`text.ts`、`html.ts`、`ansi.ts`、`mime.ts`、`frontmatter.ts`、`changelog.ts`。
- 交互与辅助：`terminal-question.ts`、`open-browser.ts`、`sleep.ts`、`abort.ts`、`deprecation.ts`、`pi-user-agent.ts`、`syntax-highlight.ts`、`tool-result-images.ts`、`paths.ts`、`web-url.ts`。
依赖方向单向向外：utils 不反向依赖业务层，仅依赖 Node 内置模块、`cross-spawn`、以及同包内的 `../config.ts`（获取 `getBinDir`/`VERSION`）。
