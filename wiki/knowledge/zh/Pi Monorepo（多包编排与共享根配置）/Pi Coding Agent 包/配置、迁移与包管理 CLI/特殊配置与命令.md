受管安装要求 `PI_MANAGED_INSTALL_ROOT` 指向包含 `managed-install.json`（`kind: "pi-managed-install"`、`schemaVersion: 1`、`layout: "releases-v1"`）的根目录，其下需有 `staging/`、`releases/<version>/`、`current-version`；可通过 `PI_INSTALLER_API_BASE` 覆盖默认 `https://pi.dev/api/installer/releases`；Windows 上仅 npm/pnpm 支持自更新，且 npm 自更新前会调用 `quarantineWindowsNativeDependencies` 清理 Windows 隔离区。
