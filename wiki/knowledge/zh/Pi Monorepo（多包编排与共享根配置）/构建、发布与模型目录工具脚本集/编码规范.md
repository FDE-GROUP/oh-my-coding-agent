- 脚本统一使用 ES Module 语法（`.mjs`）并通过 `#!/usr/bin/env node` shebang 可直接执行。
- 对外暴露的库式脚本以具名 `export function` 形式导出，供其他脚本 import 复用（如 `produceArtifactSet`、`getPublicWorkspacePackages`、`findPackageDirectories`）。
- 子进程调用统一通过 `npm-command.mjs` 的 `execNpmSync` 包装，以处理 Windows 下 `npm.cmd` 与 `npm_execpath` 的定位。
- 可复用的数据结构（如 artifact manifest、model catalog index）采用显式 `schemaVersion` 字段配合读取时的版本校验，失败时抛出错误。
- 测试文件与对应脚本同名并以 `.test.mjs` 后缀并列放置（如 `check-pinned-deps.test.mjs`、`package-artifacts.test.mjs`）。
- 需要跨仓库共享的纯协议定义放在 `model-catalog-protocol.ts`，保持零运行时依赖以便在 Node.js 与 Cloudflare Workers 中共同运行。
