模块按职责分层组织：
- 顶层入口 `src/index.ts` 仅重新导出 builders、types、validator 与 equal，对外暴露 `compile()`、`Validator`/`CoercingValidator` 以及 `str/num/obj/tuple/union/recursive` 等构建器。
- `builders.ts` 产出普通 JSON Schema 对象，并通过 TypeScript 品牌字段 `[STATIC]` 与 TypeBox 的 `~kind`/`~unsafe` 标记在类型层绑定静态类型；`Static<S>` 根据标记选择 TypeBox 推断或品牌类型。
- `compiler.ts` 是核心编译器，基于 `checks.ts` 中的原子 check 组合（stringCheck/numberCheck/objectCheck/arrayCheck/ifCheck/oneOf 等），按值类型分组生成专用闭包，并缓存子 schema 的 check；遇到带 bookended `$dynamicRef` 的模式时抛出 `RESTART` 符号以触发二次编译（动态作用域模式）。
- `annotations.ts` 提供注解传播工具（`annotateAll`/`withFreshAnnotations`/`unevaluatedProperties` 等），仅在 draft 2020-12 且存在 `unevaluated*` 关键字时启用。
- `resolver.ts` 处理 `$ref`/`$dynamicRef` 解析与多文档注册；`coerce.ts` 实现宽松输入到目标类型的强制转换；`explain.ts` 复用 Compiler 构造错误解释；`shared.ts` 共享正则表达式；`typebox-static.ts` 桥接 TypeBox 的静态类型映射。
- `formats/` 子目录提供 JSON Schema 2020-12 定义的所有 format 检查（email/uri/uuid/ipv4/ipv6/json-pointer/regex 等），内部再分 `typebox/` 子目录存放从 TypeBox 1.3.27 适配的实现，通过 `formats/index.ts` 统一冻结导出；未传入 `formats` 选项时 `format` 仅作为注解不执行。
- 依赖方向单向：index → validator → compiler → {checks, annotations, resolver, shared}；formats 独立于主编译路径，可被按需引入。
