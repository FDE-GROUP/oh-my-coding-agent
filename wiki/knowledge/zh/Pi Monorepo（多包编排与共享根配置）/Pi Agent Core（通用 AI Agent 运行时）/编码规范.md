- 对外 API 统一通过 `src/index.ts` 重新导出，内部模块不直接对外暴露。
- 异步回调（beforeToolCall、afterToolCall、finishTurn、prepareRequest、prepareNextTurn、getSteeringMessages、getFollowUpMessages）均接受可选的 AbortSignal 参数，并在文档注释中约定不得 throw/reject，需返回安全回退值。
- 消息与上下文在循环内保持 `AgentMessage[]` 形态，仅在 LLM 调用边界通过 `convertToLlm` 转换为 pi-ai 的 `Message[]`。
- 工具结果采用 `content`（模型可见）+ `structuredContent`（程序化输出）双字段分离，错误通过 `isError: true` 而非抛错表达。
- 状态属性（tools、messages、systemPrompt）通过 getter/setter 实现浅拷贝语义，防止外部直接修改内部数组引用。
