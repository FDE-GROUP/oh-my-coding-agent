模块以 `src/types.ts` 定义统一的数据契约（`CodemodeTool`/`CodemodeResult`/`CodemodeRun` 等），由 `src/runtime/execution.ts` 中的 `Execution` 类实现跨后端的执行生命周期：管理 deadline、abort、输出、调用记录与 store，并通过 `VmLauncher` + `VmChannel` 抽象屏蔽底层差异。

- 三个具体后端均继承自 `CodemodeSandboxBase`，仅替换 launcher：
  - `runtime/host.ts` → `CodemodeSandbox`：每个执行一个 Node `worker_threads` Worker，通过 `postMessage` 通信，使用 `SharedArrayBuffer` + `Atomics` 中断标志终止 VM。
  - `runtime/inline.ts` → `InlineCodemodeSandbox`：在主线程直接 `startVm`，用 `interruptBudget` 计数 QuickJS 中断回调次数来模拟超时，并降低栈大小以防宿主栈溢出。
  - `runtime/remote.ts` → `RemoteCodemodeSandbox` + `serveCodemodeRemote`：客户端保持 host 角色，远端通过 `exchange` RPC 流式回传消息；远端复用 inline launcher 并在 Durable Object / Cloudflare isolate 中运行。
- `runtime/vm.ts` 封装 `quickjs-wasi` 的会话创建、prelude 注入与 `deliver()` 调度；`runtime/protocol.ts` 定义 `HostToWorkerMessage` / `WorkerToHostMessage` 联合类型，是 host/worker/remote 三方的唯一协议边界。
- 顶层入口 `src/index.ts` 暴露面向用户的 API；`src/portable.ts` 作为无 `node:*` 依赖的子导出，供 Cloudflare Workers/Durable Objects 使用；`src/cloudflare.ts` 提供 Wrangler 集成。
- 依赖方向单向：host/inline/remote → execution → vm/protocol → wasm；types 被所有层引用但不反向依赖。
