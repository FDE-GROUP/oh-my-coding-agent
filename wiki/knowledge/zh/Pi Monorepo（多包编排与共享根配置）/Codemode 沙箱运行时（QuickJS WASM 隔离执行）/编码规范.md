- 每种运行后端都通过继承 `CodemodeSandboxBase` 并传入一个 `VmLauncher` 工厂来实现，launcher 负责返回 `VmChannel`（`post`/`stop`）并桥接到底层 transport。
- host 与 worker/remote 之间的所有消息都通过 `protocol.ts` 中的联合类型（`HostToWorkerMessage` / `WorkerToHostMessage`）进行 discriminated union 分发，并由 `is*Message` 守卫函数校验。
- 错误统一归一为 `CodemodeError` 字面量联合（`script`/`timeout`/`aborted`/`sandbox`），由 `errorMessage` 辅助函数从任意 throw value 提取 message。
- 对外导出的公共 API 集中在 `src/index.ts` 和 `src/portable.ts` 两个 barrel 文件中，后者刻意排除 `node:*` 依赖以适配 Cloudflare 环境。
- 工具与全局名在进入 VM 前经 `toCodemodeIdentifier` 规范化，并以 JSON 字符串形式在 bridge 上往返，避免脚本修改原型污染序列化过程。
