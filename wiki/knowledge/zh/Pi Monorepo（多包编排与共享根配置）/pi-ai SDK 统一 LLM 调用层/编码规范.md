- 每个新增提供商需同时提供 `src/providers/<name>.ts`（ProviderDefinition）、`<name>.models.ts`（模型枚举）以及 `src/providers/data/<name>.json`（模型清单），并在 `all.ts` 中注册。
- API 适配器文件采用 `<provider>-<feature>.ts` 命名，并通过 `*.lazy.ts` 变体按需加载以降低冷启动开销。
- OAuth 实现遵循 `auth/oauth/<provider>.ts` 结构，通过 `resolve()` 根据环境变量自动选择 API Key 或 OAuth 流程。
- 跨模块共享的基础设施（重试、事件流、错误归一化、诊断等）统一放在 `src/utils/`，避免在各 provider 内重复实现。
