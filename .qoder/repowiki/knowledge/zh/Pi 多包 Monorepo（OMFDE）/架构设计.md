根目录作为 pnpm workspace 编排层，通过 `pnpm-workspace.yaml` 将 `packages/*`、`apps/*`、`extensions/*` 及若干 examples 纳入同一依赖图；顶层 `package.json` 以 `pnpm --filter` 按依赖顺序串联各子包的 build 脚本（telemetry → schema → tui → codemode → mcp → ai → agent-core → coding-agent），形成单向依赖链：coding-agent 消费 agent-core，agent-core 消费 ai/mcp/telemetry，ai 消费 schema，tui/codemode 独立供 CLI 使用。

跨子模块共享的基础设施集中在根级配置：`tsconfig.base.json` 提供 ES2024 + Node16 + strict + verbatimModuleSyntax 的统一 TS 编译选项，所有子包继承该 base；`biome.json` 在仓库根集中定义 lint/format 规则并显式 include `packages/*/src`、`apps/*/src`、`extensions/*/src`，使代码风格校验覆盖全部子包；`vitest.base.ts` 为测试提供共享 vitest 配置。

发布流程由 `scripts/` 下的 Node 脚本驱动（publish.mjs、release.mjs、local-release.mjs、pack-packages.mjs 等），配合 `version:*` 脚本调用 `pnpm version -r` 同步所有包版本，并通过 husky 在 pre-commit/pre-push 阶段触发 check 流水线。
