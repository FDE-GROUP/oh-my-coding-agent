- 每个提供商同时提供 `<provider>.ts` 与 `<provider>.lazy.ts`，后者用 `lazyApi(() => import('./<provider>.ts'))` 包装，仅在首次调用时加载 SDK。
- 适配器统一导出 `stream: StreamFunction<...>` 和 `streamSimple: StreamFunction<...>`，内部通过 `new AssistantMessageEventStream()` 构造流，并在 try/catch 中推送 `start` / `text_delta` / `toolcall_*` / `thinking_*` / `done` / `error` 事件。
- 请求参数构建先调用 `buildBaseOptions(model, context, options)` 合并基础选项，再叠加提供商特有字段（如 toolChoice、reasoning_effort、prompt_cache_key）。
- API Key 获取统一通过 `getClientApiKey(provider, options.apiKey, options.headers)`，拒绝未提供的 key 并抛出明确错误。
- Thinking / reasoning 能力通过 `model.compat.thinkingFormat`（zai/qwen/chat-template/baseten/deepseek/openrouter/string-thinking 等）分支写入不同字段，避免硬编码到适配器逻辑。
- 对不支持的 JSON Schema 关键字或超限 strict tools，通过 `constrained-sampling.ts` 抛出的 `UnsupportedStrictJsonSchemaError` 或 `isStrictToolLimitErrorMessage` 检测进行降级回退。
