三个文件是并列的 Provider 工厂函数，统一通过 `createProvider` 注册到框架的 Provider 系统，并复用 `openAICompletionsApi` 作为底层 HTTP 客户端。
- `xiaomi.ts`：基础 Provider，baseUrl 指向 `api.xiaomimimo.com/v1`，使用环境变量 `XIAOMI_API_KEY`。
- `xiaomi-token-plan-cn.ts` / `xiaomi-token-plan-ams.ts`：分别对应中国区与 AMS 区域的 Token Plan 服务，各自独立 baseUrl（`token-plan-cn.xiaomimimo.com` / `token-plan-ams.xiaomimimo.com`）和独立的 API Key 环境变量（`XIAOMI_TOKEN_PLAN_CN_API_KEY` / `XIAOMI_TOKEN_PLAN_AMS_API_KEY`），并通过同名的 `*.models.ts` 文件声明可用模型列表。
依赖方向单向向外：本模块仅依赖 `../api/openai-completions.lazy.ts`、`../auth/helpers.ts` 与 `../models.ts`，不反向引用上层逻辑。
