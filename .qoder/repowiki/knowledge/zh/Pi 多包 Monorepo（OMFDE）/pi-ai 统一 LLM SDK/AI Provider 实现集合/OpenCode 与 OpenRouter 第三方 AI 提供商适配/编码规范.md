- Provider 工厂函数通过 `createProvider` 组装，将 id/name/auth/models/api/classifiers/images 作为配置对象返回，而非直接实例化 HTTP 客户端。
- 模型清单通过展开 `Object.values(OPENROUTER_MODELS)` 等常量数组拼接，chat/image/classifier 三类模型分别维护在独立的 `.models.ts` 文件中。
- 对上游 API 适配器进行横向增强时，使用装饰器式包装（如 `withOpenCodeSessionHeader(...)`），保持适配器本身无感知。
- 外部服务的价格/元数据结构以独立接口（如 `OpenRouterPricing`、`OpenRouterModel`）描述，并在转换函数中做防御性解析（空值、负数、缺失字段回退默认值）。
