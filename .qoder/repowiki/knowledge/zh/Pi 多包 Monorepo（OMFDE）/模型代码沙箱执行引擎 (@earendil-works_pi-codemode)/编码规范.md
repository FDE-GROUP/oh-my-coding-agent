- 每种宿主都通过实现 `VmLauncher` 返回 `VmChannel` 来接入核心，使 `CodemodeSandboxBase` 无需感知 worker、in-thread 或 RPC 的差异。
- VM 与宿主之间的所有交互都通过 `protocol.ts` 中的带 `type` 字段的联合消息类型进行，接收端先经 `isWorkerToHostMessage` 守卫再 switch 分发。
- 跨边界的值一律走 JSON 序列化（`JSON.stringify` / `parseBridgeJson`），并在解码失败时抛出内部 `BridgeError`，由上层统一转为 `kind: "sandbox"` 错误。
- 对外 API 通过多个 entry point（`index.ts`、`portable.ts`、`cloudflare.ts`）按环境裁剪导出，避免把 `node:*` 或 `cloudflare:workers` 引入到轻量入口。
- 常量与上限（如 `MAX_OUTPUT_CHARS`、`DEFAULT_INTERRUPT_BUDGET`、`RESERVED_GLOBALS`）集中在各自源文件中作为模块级常量，由多处消费而非硬编码。
