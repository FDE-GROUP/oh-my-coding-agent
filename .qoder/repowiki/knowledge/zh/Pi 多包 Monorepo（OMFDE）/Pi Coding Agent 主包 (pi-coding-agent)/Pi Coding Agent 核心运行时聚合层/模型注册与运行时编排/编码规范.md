- Provider 组合采用装饰器式包装：`withRemoteCatalog`、`withVirtualModels`、`withPersonalizedCatalog` 等函数接收一个 Provider 并返回增强后的 Provider，而非继承或类组合。
- 认证信息通过 `composeApiKeyAuth` / `composeOAuthAuth` 分别组装，并在 `withConfiguredAuth` 中统一合并 headers 与可选的 `Authorization: Bearer` 注入，调用方不直接拼接凭证。
- 模型查找结果统一用 discriminated union 表达（如 `ModelReferenceResult` 的 resolved/ambiguous/not-found、`ResolveCliModelResult` 的 model/error/warning），由调用方处理每种分支。
- 异步 I/O 均接受 `AbortSignal` 并在入口处调用 `throwIfAborted()`，配合 `raceWithAbortSignal` 保证取消路径可中断。
- 对远端目录与本地 JSON 的读写通过 `context.publish({ update, persist })` 回调原子地更新内存快照并持久化，避免中间态泄漏。
