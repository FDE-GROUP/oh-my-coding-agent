本模块由三个相互独立的基础设施文件组成，均作为无状态的顶层 API 暴露给 core 层其他组件：
- `event-bus.ts`：基于 Node `EventEmitter` 封装的轻量发布/订阅通道，对外暴露 `EventBus` / `EventBusController` 接口；所有 handler 被包装为 async 并 catch 异常后 `console.error`，避免单个事件处理器崩溃传播；`clear()` 通过 `removeAllListeners()` 释放资源。
- `http-dispatcher.ts`：基于 `undici` 的全局 HTTP 调度器配置入口。通过 `configureHttpDispatcher` 安装自定义 `EnvHttpProxyAgent`（禁用 H2、启用 proxyTunnel、设置 body/header timeout），并通过 `undici.setGlobalDispatcher` 替换全局 dispatcher；同时检测是否替换过 `globalThis.fetch`，仅在未替换时调用 `undici.install()` 以保持一致性。提供 `parseHttpIdleTimeoutMs` / `formatHttpIdleTimeoutMs` 与 `HTTP_IDLE_TIMEOUT_CHOICES` 常量用于配置解析与 UI 展示；`applyHttpProxySettings` 将代理地址写入 `HTTP_PROXY` / `HTTPS_PROXY` 环境变量。
- `output-guard.ts`：对 `process.stdout.write` 进行原地劫持，将 stdout 重定向到 stderr，并提供 `writeRawStdout` / `flushRawStdout` / `waitForRawStdoutBackpressure` 等工具函数绕过劫持直接写原始 stdout；使用链式 Promise (`rawStdoutWriteTail`) 串行化写入并处理 ENOBUFS/EAGAIN/EWOULDBLOCK 背压重试。
依赖方向单向向外：三者仅依赖 Node 内置模块与 undici，不反向依赖业务逻辑。
