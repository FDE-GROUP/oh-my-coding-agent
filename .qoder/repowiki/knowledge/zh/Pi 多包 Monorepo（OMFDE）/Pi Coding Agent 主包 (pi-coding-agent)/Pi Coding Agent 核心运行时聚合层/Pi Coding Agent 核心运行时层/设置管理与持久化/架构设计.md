模块由三个文件构成清晰的三层：
- `settings-schema.ts`：基于 TypeBox (`@sinclair/typebox`) 声明 `SettingsSchema`，导出 `Settings` 等 TypeScript 类型，作为运行时类型契约与 JSON Schema 的唯一来源。
- `settings-defaults.ts`：集中维护 `SETTINGS_DEFAULTS` 常量对象，被 schema 和 manager 共同引用，保证默认值单点一致。
- `settings-manager.ts`：核心运行时层，通过 `SettingsStorage` 接口（`FileSettingsStorage` / `InMemorySettingsStorage`）抽象存储后端，使用 `proper-lockfile` 对 `settings.json` 加锁读写；提供 `global` 与 `project` 两个 scope，按 `deepMergeSettings` 递归合并，并通过 `+name`/`-name` 语法支持 `defaultTools` 增量覆盖。
依赖方向单向：manager → defaults + schema；schema 不反向依赖 manager。写入路径经 `enqueueWrite` 串行化到 `writeQueue`，并通过 `modifiedFields` / `modifiedNestedFields` 追踪变更字段以最小化磁盘写入。旧格式（`queueMode`、`websockets`、旧 `skills` 对象、`retry.maxDelayMs`）在 `migrateSettings` 中统一迁移。
