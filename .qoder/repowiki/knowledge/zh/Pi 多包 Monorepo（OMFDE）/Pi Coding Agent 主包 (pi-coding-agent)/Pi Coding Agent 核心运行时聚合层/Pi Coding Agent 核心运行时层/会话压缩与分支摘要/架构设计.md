模块按职责拆分为三个文件并通过 `index.ts` 统一导出：
- `compaction.ts`：核心压缩管线，包含令牌估算（`estimateTokens`/`estimateContextTokens`）、切点查找（`findCutPoint`/`findProjectedCutPoint`）、摘要生成（`generateSummary`/`generateSummaryWithUsage`/`completeSummarization`）以及主入口 `prepareCompaction` + `compact`；依赖 `../session-manager.ts` 获取投影与会话条目，依赖 `../messages.ts` 做消息转换。
- `branch-summarization.ts`：处理树形会话导航时离开分支的摘要，提供 `collectEntriesForBranchSummary`、`prepareBranchEntries`、`generateBranchSummary`，复用 `compaction.ts` 的 `completeSummarization` 与 `utils.ts` 的文件操作追踪。
- `utils.ts`：纯工具层，定义 `FileOperations` 结构并提供 `extractFileOpsFromMessage`、`computeFileLists`、`formatFileOperations`、`serializeConversation` 及共享系统提示 `SUMMARIZATION_SYSTEM_PROMPT`。

依赖方向单向：`branch-summarization.ts` → `compaction.ts` → `utils.ts`；I/O（模型调用、重试、流式输出）集中在 `completeSummarization` 这一 choke point，由 `retryAssistantCall` 包装以支持可配置的重试策略。所有 prompt 文本以常量形式内联在各自文件中，便于扩展通过 `customInstructions` / `replaceInstructions` 注入。
