- 每个 SDK 示例是独立的编号脚本，使用 `await createAgentSession()` 创建会话后通过 `session.subscribe` 监听 `message_update` 事件并以 `text_delta` 形式输出流式内容。
- 自定义工具统一通过 `defineTool({ name, label, description, parameters: Type.Object(...), execute })` 定义，并在默认导出的工厂函数中调用 `pi.registerTool` 注册。
- 示例入口文件采用 JSDoc 风格的顶部注释说明用途，并在 try/finally 中确保 `session.dispose()` 或 `client.stop()` 等资源释放。
- 扩展示例遵循 `index.ts` 导出一个接收 `ExtensionAPI` 的工厂函数，内部通过 `pi.registerXxx` 系列方法挂载能力。
