- 重试逻辑采用「策略 + 回调」模式：定义 RetryPolicy / ProviderRetryOptions 配置对象，并通过 onRetryScheduled / onRetryAttemptStart / onRetryFinished 等可选回调向外暴露生命周期钩子。
- 可重试错误通过预编译的正则表达式集合（NON_RETRYABLE_PROVIDER_LIMIT_ERROR_PATTERN / RETRYABLE_PROVIDER_ERROR_PATTERN）进行文本匹配分类，而非硬编码 if/else 分支。
- 对第三方 SDK 的重试行为保持镜像：provider-retry.ts 显式注释说明其策略与 OpenAI/Anthropic SDK 对齐，并在升级 SDK 时需同步审查。
- 所有需要等待的操作（sleep、backoff、AbortSignal）都通过自定义 abortableSleep / sleep 包装 Promise，监听 AbortSignal 的 'abort' 事件并清理定时器，避免悬挂计时器。
- 错误统一封装为带结构化字段的 Error 子类或 ModelsError，携带 status / headers / provider / model 等上下文，便于上层区分可重试与不可重试场景。
- 工具函数优先返回结果而非抛出异常：parseToolCallArguments、parseStreamingJson、getProxyForUrl 等在解析失败时返回默认值（空对象、undefined、空字符串）并附带错误描述字段。
