- Token 命名采用三段式前缀：`--dsw-static-*` 表示静态色板、`--dsw-alias-*` 表示语义别名、`--dsh-*` 表示设计系统非颜色值，业务代码通过 Tailwind 的 `--color-dsw-*` 等变量间接消费。
- 明暗主题通过 `[data-theme="dark"]` 选择器覆盖同一组 CSS 变量，而非使用 CSS 媒体查询或 JS 状态。
- 新增 token 时先在 `app-tokens.css` 或 `generated.css` 中以 `--dsw-*`/`--dsh-*` 形式声明，再在 `app.css` 的 `@theme` 块中映射到 Tailwind 语义变量，保持 token 与框架解耦。
