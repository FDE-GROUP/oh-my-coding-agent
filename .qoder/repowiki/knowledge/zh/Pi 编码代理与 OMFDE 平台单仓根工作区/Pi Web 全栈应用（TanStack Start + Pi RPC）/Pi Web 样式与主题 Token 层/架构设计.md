模块以 `app.css` 作为唯一入口，通过 `@import "tailwindcss"` 引入 Tailwind v4，并级联导入 `tokens/generated.css`（由脚本生成）和 `tokens/app-tokens.css`（手写非颜色 token）。`generated.css` 仅包含 Pi Web 使用的 `--dsw-*` token 子集，来源注释指向 DSH 0.2.2-rc.1 的 `design-platform.css`；`app-tokens.css` 定义 `--dsh-*` 系列（字体栈、圆角、过渡曲线、阴影、焦点环宽度等）非颜色值。`app.css` 中的 `@theme` 块将 `--dsw-alias-*` 别名映射到 Tailwind 的 `--color-dsw-*`、`--radius-dsw-*`、`--shadow-dsw-*` 等语义化变量，使业务组件通过 Tailwind 类名消费 token。`@layer base` 中集中声明 `html`/`body`/`::selection`/`*` 滚动条等全局重置，并通过 `[data-theme="dark"]` 切换明暗模式。依赖方向单向：`app.css` → `tokens/*`，无反向引用。
