模块按职责分为两个子目录：
- `src/server/`：Node.js 侧运行时层。`jsonl.ts` 实现基于 LF 的增量 JSONL 分帧器（避免 readline 在 U+2028/U+2029 处截断）；`runtime.ts` 的 `SessionRuntime` 通过 `child_process.spawn` 启动 `pi --mode rpc` 子进程，维护命令 ID→Promise 映射、超时、stderr 缓冲、扩展弹窗自动取消与 `status/record/exit` 事件总线；`runtime-manager.ts` 的 `RuntimeManager` 以 session id 为键注册多个 `SessionRuntime`，实现懒启动、并发上限（默认 4）、空闲回收（30 分钟）与定时 sweep，并通过 `getRuntimeManager()` 暴露进程级单例（挂载于 `globalThis.__piWebRuntimeManager`）；`health.ts` 使用 TanStack Start 的 `createServerFn` 暴露 GET `/health` 端点。
- `src/lib/`：浏览器侧共享工具。`theme.ts` 通过内联脚本 `THEME_INIT_SCRIPT` 在水合前设置 `html[data-theme]`，并提供偏好读写、系统主题监听与发丝线宽度计算；`viewport.ts` 提供 React Hook `useViewport`，默认宽度 1280 以避免 SSR/CSR 水合不一致。
依赖方向单向：`runtime-manager.ts → runtime.ts → jsonl.ts`，`lib/` 不依赖 `server/`。
