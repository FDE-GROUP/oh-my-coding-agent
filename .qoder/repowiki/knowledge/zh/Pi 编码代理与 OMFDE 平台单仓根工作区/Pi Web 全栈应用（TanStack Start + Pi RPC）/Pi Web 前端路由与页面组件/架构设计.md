模块由三部分组成：
- 路由层 `routes/`：遵循 TanStack Router 的 file-based routing，`__root.tsx` 通过 `createRootRoute` 注入 HTML shell（含 `<HeadContent>`、`<Scripts>` 和主题初始化脚本），`index.tsx` 作为根页面通过 loader 调用 `server/health.ts` 并渲染 `AppFrame`；`routes/api/` 下的文件使用 `createFileRoute` 的 `server.handlers` 字段暴露 RESTful API（如 `/api/sessions`、`/api/sessions/$sessionId`、`$sessionId.commands`、`$sessionId.events`），直接依赖 `server/runtime-manager.ts` 管理会话生命周期。
- 组件层 `components/`：按职责分目录——`layout/` 提供 `AppFrame`（响应式抽屉/侧边栏切换）、`Sidebar`、`RightPanel`、`ThemeControl`；`primitives/` 暴露无业务语义的原子组件 `Button`、`IconButton` 及图标集合 `icons.tsx`；`conversation/` 放置占位组件。
- 入口 `router.tsx`：封装 `getRouter()` 工厂函数，集中配置 `scrollRestoration`、`defaultPreload: 'intent'` 等全局选项，并通过 `Register` 模块声明将类型注册到 TanStack Router。
依赖方向单向：routes → components → primitives；API route handlers 仅依赖 server 层，不反向引用 UI 组件。
