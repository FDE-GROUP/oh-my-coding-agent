模块仅包含一个 Node.js ESM 脚本 `bin/omfde.mjs`，作为 npm bin 入口（package.json 中声明 `bin.omfde`）。其职责单一：从 `import.meta.url` 推导仓库根路径，优先查找本地 `node_modules/.bin/pi`（Windows 下为 `pi.cmd`），回退到 PATH 中的 `pi`；通过 `child_process.spawn` 以 `stdio: 'inherit'` 方式启动子进程，透传除首个 `--`（pnpm 分隔符）之外的所有参数，并设置 `OMFDE_PLATFORM=1` 环境变量供 Pi 侧识别平台化调用。子进程的 exit code 与信号（如 Ctrl+C）被原样回传给父进程，使 omfde 在行为上等价于直接调用 pi。依赖方向单向指向外部包 `@earendil-works/pi-coding-agent`，当前未使用。
