模块以 `src/index.ts` 为唯一入口，按职责拆分为四个文件：
- `types.ts`：集中声明所有公共类型（`AgentMessage`、`AgentTool`、`AgentEvent`、`AgentLoopConfig`、`AgentState`、`StreamFn` 等），是其他文件的契约边界。
- `agent-loop.ts`：无状态的低层循环实现，导出 `runAgentLoop` / `runAgentLoopContinue` / `agentLoop` / `agentLoopContinue`，负责转译 `AgentMessage[]` ↔ `Message[]`、工具声明差异注入 (`declareToolChanges`)、assistant 响应流式消费、顺序/并行两种工具执行路径以及 `beforeToolCall` / `afterToolCall` 钩子。
- `agent.ts`：有状态的 `Agent` 类，维护 `_state`、两个 `PendingMessageQueue`（steering/follow-up）、订阅者集合和当前运行 (`ActiveRun`)；将配置包装成 `AgentLoopConfig` 并委托给低层 loop，同时把 loop 事件归约为 UI 可读的 `AgentEvent`。
- `proxy.ts`：独立的 `streamProxy` 实现，通过 HTTP SSE 到远端 `/api/stream`，在客户端重建 `AssistantMessage` partial，作为可替换的 `StreamFn` 注入。
- `stream-fn.ts`：默认 `StreamFn` 工厂（由 `getDefaultStreamFn` 导出）。
依赖方向单向：`agent.ts` → `agent-loop.ts` → `stream-fn.ts`，`proxy.ts` 独立于 loop 并通过 `StreamFn` 接口接入。外部仅依赖 `@earendil-works/pi-ai` 与 `@earendil-works/pi-schema`。
