- 每个 schema 文件顶部声明 `$schema`、`$id`（以 https://pi.dev/schemas/ 为命名空间）以及提示“由 TypeScript 源码生成”的 $comment。
- 可选字段通过 anyOf 同时声明基础类型与 const 字面量枚举值，并附带 description 说明各取值含义。
- 重复出现的复杂结构（如 ModelThinkingLevel、ModelCost、ColorValue、KeybindingValue）集中放在文件末尾的 $defs 中，通过 $ref 引用。
- 需要按任意键名索引的对象属性统一使用 patternProperties: {"^.*$": ...} 表达动态键。
- 废弃字段保留但添加 deprecated: true，并在 description 中标明迁移目标（如 queueMode→steeringMode、websockets→transport）。
