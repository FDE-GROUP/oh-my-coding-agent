- 对外暴露的渲染器（如 ToolHtmlRenderer）采用接口 + createXxxFactory(deps) 工厂模式，依赖通过对象注入而非全局单例。
- 模板渲染统一通过 readFileSync 加载 template.* 与 vendor/* 资源，并用字符串 replace 替换 `{{PLACEHOLDER}}` 占位符完成注入。
- 会话数据在写入前经 JSON.stringify + Buffer.toString('base64') 编码，避免 HTML 中转义问题，并在浏览器端直接反序列化。
- 可选渲染路径（如工具自定义渲染）返回 undefined 时调用方回退到结构化结果渲染，错误被 try/catch 吞掉以保证导出鲁棒性。
