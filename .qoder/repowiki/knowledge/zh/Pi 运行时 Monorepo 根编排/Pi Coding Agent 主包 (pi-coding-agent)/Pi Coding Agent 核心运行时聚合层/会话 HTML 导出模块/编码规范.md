- 对外 API 同时接受对象选项或字符串路径（`typeof options === "string" ? { outputPath: options } : options || {}`），保持 CLI 与程序化调用兼容。
- 模板渲染采用「读取文件 + 字符串占位符替换」模式，CSS/JS/Markdown/Highlight 等资源通过 `{{PLACEHOLDER}}` 注入，避免使用模板引擎。
- 可选的外部能力通过接口抽象（如 `ToolHtmlRenderer`、`ToolHtmlRendererDeps`），未实现时返回 `undefined` 让调用方回退到结构化结果渲染。
- 颜色处理统一经 `parseColor` → `getLuminance` → `adjustBrightness` 管线，并以 `rgb(r,g,b)` 形式输出，便于根据明度自动推导浅色/深色背景变体。
