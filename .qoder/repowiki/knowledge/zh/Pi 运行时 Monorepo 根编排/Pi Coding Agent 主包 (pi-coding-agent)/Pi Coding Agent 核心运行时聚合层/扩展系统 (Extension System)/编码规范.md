- 扩展 API 方法统一通过 `assertActive()` 校验 runtime 是否已初始化且未被 invalidate，防止 session 替换后继续使用旧 ctx。
- 事件以具名接口 + `type` 字面量区分，并通过联合类型（如 `SessionEvent`、`BeforeAgentStartEvent`）聚合，新增事件需同时更新聚合类型。
- 扩展注册（tool/command/shortcut/flag/provider/mcp-server/virtual-model）先写入扩展自身的 Map，再由 loader.commit() 批量提交到共享 runtime，避免部分加载状态泄漏。
- 对宿主能力的访问通过 `ExtensionRunner.bindCore` / `bindCommandContext` 注入的函数指针完成，而非直接依赖宿主模块，保持加载期与运行期解耦。
- 工具定义通过 `defineTool` 包裹以保持 TypeBox 参数类型的推断，并在 `registerTool` 时校验 parameters 必须为对象。
