- 每个模式导出一个顶层入口函数（`runPrintMode`、`runRpcMode`、`InteractiveMode`），统一接收 `AgentSessionRuntime` 作为运行时宿主。
- stdout 写入一律通过 `output-guard.ts` 的 `writeRawStdout` / `flushRawStdout` / `takeOverStdout`，并在需要时配合 `waitForRawStdoutBackpressure` 做背压控制。
- SIGTERM/SIGHUP 信号处理器在两个模式中采用相同模式：注册清理回调数组、首次信号触发优雅 dispose、重复信号直接 `process.exit`。
- JSON 事件输出统一经由 `toJsonEvent` 转换后再序列化，保证 print 与 rpc 两种模式的流式事件结构一致。
- RPC 命令通过 `switch (command.type)` 分派到按语义分组（Prompting / State / Model / Thinking / Queue Modes / Compaction / Retry / Bash / Session / Messages / Commands）的 case 块，未知命令返回 `error(id, type, ...)`。
