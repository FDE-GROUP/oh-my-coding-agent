模块按职责划分为四个子目录：
- `components/layout/`：应用级骨架（`AppFrame.tsx` 作为根容器，组合 `Sidebar`、`RightPanel`、`ThemeControl`），负责工作区切换、会话列表、运行时状态轮询与响应式抽屉布局。
- `components/conversation/`：对话业务层，`Conversation.tsx` 通过 `useReducer(conversationReducer, initialConversationState)` 管理消息流，使用 `openEventStream` 订阅后端事件并驱动 `Composer`、`MessageList`、`SessionBar` 等子组件。
- `components/primitives/`：无业务语义的原子组件（`Button`、`IconButton`、`icons.tsx`），仅组合 Tailwind 类名与 SVG 图标。
- `components/tools/ToolCard.tsx`：工具卡片展示。

样式体系位于 `styles/`：`app.css` 通过 `@import "tailwindcss"` 引入 Tailwind，并通过 `@theme` 将 `generated.css` 中的 `--dsw-*` CSS 变量映射为 Tailwind 颜色/半径/阴影；`tokens/app-tokens.css` 定义非颜色 token（字体栈、圆角、过渡曲线、阴影、焦点环），由 `data-theme="dark"` 覆盖深色模式。组件全部通过 Tailwind 原子类 + `clsx` 拼接 className，不写内联样式。依赖方向单向向下：layout → conversation → primitives/tools，所有 API 调用统一走 `../../lib/api.ts`，类型来自 `../../server/*.ts`。
