- 每个导出函数/类型都带有 JSDoc 注释并标注 `@internal`，对外暴露的类型集中在文件顶部声明。
- HTTP 调用统一遵循 fetch → response.ok 检查 → readError 抛出 Error → JSON 强转返回值的模式。
- 对 window/document/localStorage 等浏览器 API 的访问前用 `typeof window === "undefined"` 守卫，使模块可被服务端渲染环境安全 import。
- 副作用型能力（如 watchSystemTheme、installHairline、openEventStream）返回取消函数，由调用方负责清理。
