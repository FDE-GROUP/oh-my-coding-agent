模块按职责拆分为五个独立文件，彼此无相互依赖，仅被上层 React 组件消费：
- `api.ts`：封装所有 `/api/*` 请求（会话 CRUD、RPC 命令、文件搜索/展开、运行时与工作区查询）以及基于 `EventSource` 的 SSE 事件流订阅，统一通过 `readError` 解析错误响应。
- `conversation.ts`：实现一个 Redux 风格的 reducer（`conversationReducer`），将快照与 SSE 事件归约为包含消息、流式文本、工具执行状态和待发送队列的不可变 `ConversationState`。
- `images.ts`：在浏览器内使用 `createImageBitmap` + Canvas 将图片缩放至长边 ≤2048px、质量迭代压缩至 ≤5MB，输出 base64 与预览 URL。
- `theme.ts`：管理 `light|dark|system` 偏好，通过写入 `html[data-theme]` 与 CSS 变量应用主题，并提供 SSR-safe 的内联初始化脚本 `THEME_INIT_SCRIPT` 避免闪屏。
- `viewport.ts`：React Hook `useViewport`，以默认宽度 1280 保证 SSR/CSR 水合一致。
依赖方向单向：本模块只依赖浏览器原生 API 与 React hooks，不反向引用任何业务组件。
