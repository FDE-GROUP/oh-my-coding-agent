scripts 目录是一组扁平的 Node.js (`.mjs`) 与 Shell (`.sh`) 工具，按职责分为几类：
- 发布流水线入口：`release.mjs` 编排版本提升、CHANGELOG 更新、Nix model catalog pin、构建、测试、打 tag 与推送；`publish.mjs` 基于 `package-artifacts.mjs` 产出 tarball 并调用 npm publish。
- 包发现与打包：`package-workspaces.mjs` 递归扫描 `packages/` 下含 `package.json` 的目录；`release-packages.mjs` 过滤非 private 包；`package-artifacts.mjs` 通过 `npm pack --ignore-scripts` 生成带 sha512 integrity 的 tarball 与 `manifest.json`（含 schemaVersion），并提供 `produceArtifactSet` / `readArtifactSet` 读写 API。
- 公共基础设施：`npm-command.mjs` 封装跨平台 npm 调用（Windows 走 `npm_execpath`）；`biome-check.mjs`、`check-entry-graphs.mjs`、`check-pinned-deps.mjs`、`check-runtime-deps.mjs`、`check-ts-relative-imports.mjs`、`npm-audit.mjs` 等是 CI 校验脚本。
- 模型目录协议与发布：`model-catalog-protocol.ts` 是与 pi.dev 仓库共享的纯类型/函数定义（无运行时依赖，可运行于 Cloudflare Workers），由 `update-model-catalog-pin.mjs`、`publish-model-catalog.mjs`、`diff-model-catalog.mjs`、`generate-thinking-capabilities.mjs` 等消费。
- 编码代理相关：`build-coding-agent-bundle.mjs`、`coding-agent-smoke.mjs`、`smoke-test-codemode-binary.mjs`、`profile-coding-agent-node.mjs`、`agent-treeshake-smoke-entry.ts`、`browser-smoke-entry.ts` 围绕 coding agent 的构建与冒烟测试。
- 本地工作流：`local-package-install.mjs`、`use-local-packages.mjs`、`preview-packages.mjs`、`local-release.mjs`、`sync-versions.js`、`create-source-archive.sh`、`build-binaries.sh`、`auto-pi.sh` 等辅助本地开发与源码归档。
依赖方向自顶向下：CLI 入口 → 领域工具（artifact/package/coding-agent/model-catalog）→ 底层共享模块（`npm-command`、`package-workspaces`、`release-packages`），无反向依赖。
