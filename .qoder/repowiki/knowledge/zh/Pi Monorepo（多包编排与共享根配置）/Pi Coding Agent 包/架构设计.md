本包以 src/main.ts 为进程入口，src/cli.ts 作为 CLI 子命令分发器，src/rpc-entry.ts 提供 RPC 子进程入口；三者共同调用 app_bootstrap 中的 main() 完成参数解析、模式路由（interactive / rpc / print），再由 execution_modes 选择具体模式驱动 core_agent_runtime 的 AgentSessionRuntime。
builtin_extensions（codemode/llama/mcp/tool_search）通过 core_agent_runtime 的 extensions 子系统在运行时动态加载；config_and_migrations 提供统一的 settings/models/keybindings 配置解析与迁移，被 cli_commands、core_agent_runtime、execution_modes 共同消费；shared_utils 提供跨平台子进程、HTTP、图像、Git、剪贴板等底层能力供所有上层模块复用；bun_runtime 仅在 Bun 环境下替换入口与沙箱环境初始化。测试位于 test/ 下，按功能域组织，examples/ 与 docs/ 分别提供 SDK 示例与用户文档。
