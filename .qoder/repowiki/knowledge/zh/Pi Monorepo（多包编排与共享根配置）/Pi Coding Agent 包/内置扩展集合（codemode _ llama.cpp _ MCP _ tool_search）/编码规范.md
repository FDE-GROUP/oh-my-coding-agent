- 每个扩展以 `index.ts` 导出一个 `ExtensionFactory` 工厂函数，并以该工厂作为默认导出，供 CLI 或 SDK 使用者注册。
- 新扩展通过 `pi.registerTool({ ..., defaultActive: false })` 注册，默认保持非激活状态，由用户显式启用或由其他扩展按需激活。
- 体积较大或可选的运行时（MCP runtime、codemode worker）通过 `*.lazy.ts` 文件配合 `import()` 延迟加载，避免影响主流程冷启动。
- 扩展内部将 UI 交互（菜单、确认、进度条）抽离到独立的 `ui.ts`，并通过 `ExtensionCommandContext.ui` 注入，使逻辑层与展示层分离。
- 对可被第三方覆盖的扩展（codemode、tool-search、mcp）在 `builtInExtensions` 中标记 `replaceable: true`，并在注释中说明覆盖语义。
