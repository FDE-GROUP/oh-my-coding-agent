模块以 `index.ts` 集中导出 `builtInExtensions: InlineExtension[]`，每个子目录是一个独立扩展，通过 `ExtensionFactory` 函数暴露给核心扩展系统。

- `codemode/`：实现 `codemode` 工具，将脚本执行、渲染器、worker 和工具定义解耦到 `tool.ts`、`renderer.ts`、`worker.ts`、`execute.ts`，并通过 `.lazy.ts` 延迟加载；默认不激活，由 MCP 扩展在需要时启用。
- `llama/`：封装 llama.cpp 服务端通信（`client.ts`）、HuggingFace 模型发现（`huggingface.ts`）、模型注册提供者（`provider.ts`）以及 TUI 交互（`ui.ts`），对外只暴露一个 `llamaExtension` 工厂。
- `mcp/`：最复杂的扩展，负责解析 `mcp.json`、维护服务器连接生命周期、动态注册/隐藏工具、OAuth 登录、资源工具代理，并提供 `/mcp` 管理器 UI；运行时（stdio/streamable HTTP transport、OAuth、日志）通过 `runtime.lazy.ts` 懒加载以避免冷启动开销。
- `tool-search/`：最小扩展，仅注册 `tool_search` 工具以便按命名空间发现其他工具。

依赖方向单向向外：所有扩展都依赖 `../../core/extensions/types.ts` 中的 `ExtensionAPI`/`ExtensionFactory`，并可通过常量（如 `CODEMODE_TOOL_NAME`、`TOOL_SEARCH_TOOL_NAME`）互相协作，但彼此之间没有直接业务耦合。扩展标记 `replaceable: true` 允许第三方扩展覆盖同名内置扩展。
