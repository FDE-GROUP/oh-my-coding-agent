- 每个运行模式在启动时调用 `runtimeHost.setRebindSession` 注册重绑定回调，并在切换 session/fork/clone 后重新 `rebindSession` 以刷新订阅。
- SIGTERM/SIGHUP 信号处理器统一先 `killTrackedDetachedChildren()`，再用 `signalCount` 计数区分首次优雅退出与重复强制退出。
- stdout 写入统一走 `output-guard.ts` 的 `writeRawStdout` / `flushRawStdout` / `waitForRawRawStdoutBackpressure`，避免阻塞 agent 事件循环。
- RPC 命令处理采用按功能分区的 `switch (command.type)` 结构，每个分区以注释分隔符（如 `// =================================================================\n// Bash\n// =================================================================`）标注。
- 扩展 UI 在 RPC 模式下通过 `createDialogPromise` 生成带 id 的 Promise，将 `ExtensionUIDialogOptions` 转换为 `extension_ui_request` 事件，并由 `pendingExtensionRequests` Map 按 id 匹配响应。
- 对外事件流经 `toJsonEvent` 转换，剥离 `message_update` 中的 cumulative partial 快照，只保留 usage、toolCall id/name 等常量大小字段。
