- 入口脚本统一以 `#!/usr/bin/env node` 开头，并通过 `process.argv.slice(2)` 剥离自身路径后交给 `main()` 处理。
- 一次性子命令（auth/package/config/mcp）在 `main()` 中尽早匹配并直接 `process.exit`，避免进入完整的运行时初始化流程。
- 错误输出统一经 `chalk.red` 着色后写入 `console.error`，成功退出使用 `process.exit(0)`，失败使用 `process.exit(1)` 或设置 `process.exitCode`。
- 耗时阶段通过 `time(...)` 包裹并由 `printTimings` 汇总，便于启动性能分析。
