模块由三个文件组成清晰的职责分层：
- `session-manager.ts` 是核心，定义 `SessionEntry` 联合类型（message/thinking_level_change/model_change/usage/compaction/branch_summary/custom/custom_message/context_edit/label/session_info）及 `SessionHeader`，并通过 `SessionManager` 类维护内存中的 `fileEntries`、`byId`、`labelsById`、`leafId` 等索引；对外暴露 `buildContextEntries` / `buildSessionProjection` / `buildSessionContext` 等纯函数用于从条目重建 LLM 上下文，同时通过 `migrateToCurrentVersion` 链式执行 v1→v2→v3 迁移。
- `session-cwd.ts` 独立处理会话工作目录缺失问题，定义 `SessionCwdSource` 接口以最小依赖反向注入 `SessionManager`，并抛出 `MissingSessionCwdError`。
- `session-export.ts` 仅消费 `SessionManager` 的只读 API（`getBranch`/`getSessionId`/`getCwd`），将当前分支序列化为 JSONL 字符串或落盘。

依赖方向单向：export → manager；cwd 与 export 均不反向依赖彼此。文件 I/O 使用 Node `fs` 同步流（`openSync`+`readSync`+`StringDecoder`）配合缓冲读取，避免大文件全量加载；并发列表扫描通过内部 `mapWithConcurrency` 限制并行度。
