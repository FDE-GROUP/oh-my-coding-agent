模块按职责拆分为若干独立单文件，围绕 `DefaultResourceLoader`（resource-loader.ts）这一编排中心组织：
- 进程与 I/O 层：`exec.ts` 封装 `node:child_process.spawn`，提供带超时/AbortSignal/maxBuffer 的 `execCommand`；`bash-executor.ts` 在其上叠加 ANSI 清洗、流式输出与临时文件落盘，供 AgentSession 和远程执行复用。
- HTTP 层：`http-dispatcher.ts` 基于 undici 配置全局 Dispatcher、代理与空闲超时，并通过 `undici.install()` 保持 Node fetch 与 dispatcher 一致。
- 资源编排层：`resource-loader.ts` 暴露 `ResourceLoader` 接口与 `DefaultResourceLoader` 实现，协调 `package-manager.ts`（解析 npm/git/local 源、应用优先级规则 `resourcePrecedenceRank`）、`extensions/loader.ts`、`skills.ts`、`prompt-templates.ts`、`theme.ts`，并注入 `SourceInfo`。
- 包管理：`package-manager.ts` 定义 `PackageManager` 接口与 `DefaultPackageManager`，统一处理 `.gitignore/.fdignore` 忽略规则、`pi.manifest` 解析、`user/project/temporary` 三作用域以及 `+/-/!` 模式覆盖。
- 事件与状态：`event-bus.ts` 基于 `node:events` 提供带错误捕获的 `EventBusController`；`nested-tool-calls.ts` 通过 `NestedToolCallRunner` + `NestedCallRecorder` 在工具内部递归调用时记录嵌套调用链与用量。
- 可观测性：`timings.ts`（PI_TIMING=1 启动计时）、`cache-stats.ts`（计算 cache miss 浪费）、`usage-totals.ts`（聚合 Usage）、`telemetry.ts`（PI_TELEMETRY 开关）、`diagnostics.ts`（ResourceDiagnostic 类型）。`output-guard.ts` 劫持 `process.stdout.write` 以绕过 TTY 缓冲，被 package-manager 用于检测 stdout 是否已被接管。
- 辅助：`source-info.ts` 定义 `SourceInfo`、`BUILTIN_PATH_PREFIX`、合成路径识别；`experimental.ts` 仅读取 `PI_EXPERIMENTAL`；`cache-warmer.ts` 基于模型 TTL 与经济学评估定时重发请求以维持 prompt cache。
依赖方向单向向内：上层（AgentSession、CLI）依赖本模块，本模块不反向依赖上层，仅通过 SettingsManager、ModelRuntime、SessionManager 等接口解耦。
