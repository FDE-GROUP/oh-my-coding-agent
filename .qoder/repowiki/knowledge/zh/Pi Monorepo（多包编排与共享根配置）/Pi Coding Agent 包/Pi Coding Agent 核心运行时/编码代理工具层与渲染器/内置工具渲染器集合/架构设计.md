本模块按工具维度拆分为独立文件（bash.ts/edit.ts/read.ts/write.ts/grep.ts/find.ts/ls.ts），每个文件导出一个 `Pick<ToolDefinition, 'renderCall' | 'renderResult'>` 对象；`index.ts` 通过 `createAllToolRenderers()` 汇总所有渲染器并按 `ToolName` 键映射，同时提供 `withBuiltInRenderers()` 将内置渲染器合并到外部自定义定义中。

- 依赖方向单向：渲染器只引用 `../../extensions/types.ts` 的 `ToolDefinition`/`ToolRenderers` 类型以及同层 `../render-utils.ts`、`../truncate.ts`、`../path-utils.ts` 等纯工具函数，不反向依赖工具执行实现，从而避免加载 ~17 MB 的工具图。
- 共享抽象：`bash.ts` 通过 `createShellRenderers(prompt)` 工厂同时产出 bash 与 powershell 的渲染器，两者仅在提示符上不同；`render-utils.ts` 提供 `getTextOutput`/`renderToolPath`/`str` 等通用格式化能力。
- UI 框架统一使用 `@earendil-works/pi-tui` 的 `Container`/`Box`/`Text`/`Spacer`，并通过 `../../../modes/interactive/theme/theme.ts` 获取主题与语法高亮。
- edit 渲染器额外维护组件级状态（`EditRenderState`、`EditCallRenderComponent`）并异步调用 `computeEditsDiff` 生成 diff 预览，通过 `context.invalidate()` 触发重绘。
