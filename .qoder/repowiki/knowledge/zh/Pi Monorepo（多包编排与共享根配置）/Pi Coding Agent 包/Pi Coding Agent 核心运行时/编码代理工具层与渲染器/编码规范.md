- 每个工具暴露成对的 `createXxxTool(cwd, options)` 与 `createXxxToolDefinition(cwd, options)` 工厂，前者返回运行时对象，后者返回扩展元数据。
- 工具选项通过独立的 `XxxToolOptions` 接口传入，并在 `ToolsOptions` 中按字段名聚合，再由 index.ts 的分派函数透传。
- 工具名称使用集中声明的 `ToolName` 联合类型与 `allToolNames` Set 作为唯一来源，新增工具需同时更新两者。
- 长输出统一经 `OutputAccumulator` 或 `truncate*` 工具进行字节/行数截断后再返回给 LLM。
- TUI 渲染逻辑独立放在 `renderers/` 下，与工具实现文件一一对应，避免渲染代码进入无头进程。
