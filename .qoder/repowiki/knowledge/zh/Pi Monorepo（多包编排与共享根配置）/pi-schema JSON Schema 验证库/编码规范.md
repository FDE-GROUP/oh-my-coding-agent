- Schema 构建器返回普通 JSON Schema 对象，并通过 TypeScript 品牌字段（`[STATIC]` 或 TypeBox 的 `~kind`/`~unsafe`）在类型层携带静态类型，运行时不产生额外开销。
- 编译器将每个 keyword 拆分为独立的 check 工厂（如 stringCheck/numberCheck/ifCheck/oneOf），再由 `and()` 组合成最终闭包，便于缓存与复用。
- 对 draft 2020-12 特有的 `unevaluatedProperties`/`unevaluatedItems` 通过 `annotations.ts` 的 annotate 通道处理，而 draft 7 直接走 `plain()` 分支，避免不必要的注解追踪。
- Format 检查以 `FormatCheck` 函数形式集中注册在 `formats/index.ts` 的冻结对象中，默认不加载，需显式传入 `compile(schema, { formats })` 才参与校验。
- 递归 schema 通过 `recursive(id, build)` 在 schema 上设置 `$id` 并以 `$ref: id` 自引用，而非依赖 `$defs`，使发布后的 JSON 结构更简洁。
