本模块是 `packages/ai` 中面向各 LLM 提供商的适配器集合，每个文件对应一个 provider/api 组合（如 `anthropic-messages.ts`、`openai-completions.ts`、`openai-responses.ts`、`google-generative-ai.ts`、`bedrock-converse-stream.ts`、`mistral-conversations.ts`、`cloudflare.ts`、`llama-cpp-classify.ts`、`pi-messages.ts`、`openrouter-images.ts`、`typesafe-system-one.ts` 等），统一暴露 `stream` / `streamSimple`（部分还暴露 `fetchDeferred` / `cancelDeferred`）函数，签名遵循 `StreamFunction<TApi, TOptions>`，返回 `AssistantMessageEventStream`。

内部分层：
- 惰性加载入口：`lazy.ts` 提供 `lazyApi` 与 `lazyStream`，将动态 `import()` 包装成 `ProviderStreams`，首次调用时才加载具体实现并复用宿主 import 缓存；`.lazy.ts` 文件即该懒包装的导出点。
- 共享基础设施：`simple-options.ts`（通用参数构建）、`transform-messages.ts`（消息归一化、toolCallId 规范化、非视觉模型降级图片、孤儿 toolCall 补空结果）、`constrained-sampling.ts`（Grammar/JSON Schema 受限采样）、`openai-prompt-cache.ts`、`github-copilot-headers.ts`、`openai-responses-shared.ts`、`system-one-shared.ts`、`classifier-shared.ts`、`google-shared.ts` 等跨 provider 复用逻辑。
- 错误与重试：通过 `../utils/error-body.ts`、`../utils/provider-retry.ts` 统一格式化与重试。
- 依赖方向：适配器 → 共享 helper (`./constrained-sampling.ts`、`./transform-messages.ts`、`./simple-options.ts`) → `../utils/*` → `../types.ts`；适配器之间不互相引用，仅通过共享 helper 耦合。
- 类型安全：每个适配器以泛型 `Model<TApi>` 绑定到 `../types.ts` 中的 `Api` 联合成员，配合 `openai-decisions.ts` 等决策文件在编译期约束可用能力。
