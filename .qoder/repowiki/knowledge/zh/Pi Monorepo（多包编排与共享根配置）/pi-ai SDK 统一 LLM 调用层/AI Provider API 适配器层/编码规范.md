- 每个适配器文件同时导出 `stream` 与 `streamSimple` 两个函数，前者接受完整 `StreamOptions` 扩展，后者经 `buildBaseOptions` 简化后委托给前者。
- 适配器通过 `getCompat(model)` 或内联 `model.compat` 字段解析 provider 能力开关（如 `supportsMidConvoSystemMessages`、`supportsLongCacheRetention`、`thinkingFormat`），而非硬编码分支。
- 流式响应统一以 `new AssistantMessageEventStream()` 创建输出流，按 `start` → `text_delta`/`thinking_delta`/`toolcall_delta` → `*_end` → `done`/`error` 的事件序列推送，并在 try/catch 中将异常转为 `stopReason: 'error'` 的 `error` 事件。
- API Key 获取采用 `getClientApiKey(provider, options.apiKey, options.headers)` 模式：优先显式 apiKey，其次检测 `authorization`/`cf-aig-authorization` 头，否则抛出 `No API key for provider` 错误。
- 缓存保留策略统一通过 `resolveCacheRetention(cacheRetention, env)` 解析，默认 short，受 `PI_CACHE_RETENTION=long` 环境变量影响。
- 需要延迟加载的实现通过 `.lazy.ts` 文件调用 `lazyApi(() => import('./xxx'))` 包装，由宿主 import 缓存去重加载。
