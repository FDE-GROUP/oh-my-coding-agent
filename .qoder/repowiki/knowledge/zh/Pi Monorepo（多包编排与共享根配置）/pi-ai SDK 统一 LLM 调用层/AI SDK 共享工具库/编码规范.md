- 重试逻辑采用「策略 + 回调」模式：通过 `RetryPolicy` / `RetryCallbacks` 或 `ProviderRetryOptions` 传入行为，内部循环负责退避与 `AbortSignal` 中断，调用方只消费结果与钩子。
- 对第三方 SDK 抛出的异常使用「字段探测」而非类型断言：按已知 SDK 的字段顺序（如 `statusCode` → `status` → `$metadata.httpStatusCode` → `$response.statusCode`）逐一尝试提取 status/body，避免强依赖具体 SDK 版本。
- 对文本类错误统一截断：通过 `truncateErrorText` 与 `MAX_PROVIDER_ERROR_BODY_CHARS` 常量将 body 限制到固定长度，并在末尾追加 `[truncated N chars]`。
- 可中止的等待统一封装为 `abortableSleep` / `sleep(ms, signal)` 形式：内部用 `setTimeout` + `signal.addEventListener('abort', { once: true })` 清理定时器，避免内存泄漏。
- 流式解析器对外暴露不可变快照：`snapshot()` 返回新对象且永不改变，内部通过「开放路径复制 + credit 机制」控制拷贝成本，增量变更以 `JsonChange` diff 形式返回。
- 模型类型校验走「运行时检查 + 结构化错误」：先 `getModelType` / `isModelType`，再抛出 `ModelsError(provider, message)`，而非直接 throw 原生 Error。
