- 路由文件统一导出名为 `Route` 的常量，通过 `createFileRoute(path)` 创建，服务端接口在 `server.handlers` 中以 HTTP 方法键（GET/POST/DELETE 等）组织处理器。
- API route handler 中错误处理采用 try/catch 包裹，并将异常转换为 `{ error }` JSON 响应，区分 404、429、500 等状态码。
- UI 组件使用 `clsx` 组合 Tailwind 类名，并通过可选 props（如 `collapsed`、`drawer`）在同一组件内实现多态布局（侧栏展开/收起、桌面/抽屉模式）。
- 原子组件（Button、IconButton）通过 `variant` 枚举配合 `variants` 映射表驱动样式变体，而非多个独立组件。
- 路由组件通过 `Route.useLoaderData()` 读取 loader 数据，loader 与组件分离，保持纯函数式数据获取。
