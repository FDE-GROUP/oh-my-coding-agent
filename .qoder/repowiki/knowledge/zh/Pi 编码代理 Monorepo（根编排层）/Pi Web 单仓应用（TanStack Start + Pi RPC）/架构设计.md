以 `server.mjs` 为唯一进程入口：原生 `http.createServer` 直接 serve `dist/client/` 下的静态资源（带 immutable 缓存），其余请求转发给 TanStack Server 的 `fetch` 接口。
- 前端层（`src/routes`、`src/components`）通过 TanStack Router 文件路由组织页面与布局，并在 `routes/api/*` 暴露服务端 API handler。
- API handler 调用 `lib/server/runtime-manager.ts` 启动并复用 Pi RPC 子进程；子进程通过 `lib/server/jsonl.ts` 的 JSONL 协议与前端交互，由 `sessions.$sessionId.events.ts` / `commands.ts` 等 SSE 端点推送事件。
- 样式层（`src/styles`）由 Tailwind CSS 4 驱动，`scripts/generate-tokens.mjs` 将 DSH token 映射为 CSS 变量注入 `app.css`，供所有组件共享。
- 测试套件（`test/`）使用 Vitest 对 JSONL 解析器与 RuntimeManager 进行集成测试，并通过 `test/faux-extension.ts` 模拟扩展完成端到端流程。
- 所有模块共享 `#/*` path alias 指向 `src/*`，使前端、服务端与测试代码共用同一份 TypeScript 源。
