- 对外 API 以工厂函数形式暴露（如 createAgentSession），并通过 Options/Result 接口对象传递可选参数与返回值，便于扩展字段而不破坏调用方。
- 可替换的子系统（ModelRuntime、SettingsManager、SessionManager、ResourceLoader）优先从 options 注入，未提供时再在工厂内部 new 默认实现，保持测试可插拔。
- 对 Provider 的请求生命周期通过 onPayload/onResponse/onProviderStreamEvent 回调钩入 ExtensionRunner 事件总线，而非直接耦合扩展逻辑。
- 工作目录与会话元数据校验采用「issue 对象 + 专用 Error 类 + format* 辅助函数」的组合模式，便于上层统一呈现诊断信息。
