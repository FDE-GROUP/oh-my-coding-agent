- 每个工具导出成对的 `createXxxToolDefinition`（返回扩展侧 `ToolDefinition`）与 `createXxxTool`（返回核心侧 `AgentTool`），后者通过 `wrapToolDefinition` 包装前者。
- 工具的可变行为通过 `Options` + `Operations` 接口注入，并在模块内提供 `defaultXxxOperations` 作为默认实现，调用方用 `options?.operations ?? defaultXxxOperations` 合并。
- 工具参数使用 TypeBox `Type.Object({...})` 声明 schema，并通过 `Static<typeof schema>` 推导输入类型，同时为输出定义独立的 outputSchema。
- 长文本/大文件输出统一经由 `truncate.ts` 的 `truncateHead` / `truncateLine` 进行行数和字节数双重截断，并在提示中给出继续读取的 offset 建议。
- 所有对同一文件的写操作通过 `withFileMutationQueue(filePath, fn)` 串行化，不同文件仍并行执行，队列键基于 `realpath` 后的绝对路径。
- 渲染器与执行实现解耦：工具模块内部引用 `./renderers/<name>.ts` 中的 renderers，而 `renderers/index.ts` 单独聚合所有渲染器供不加载工具实现的展示进程使用。
