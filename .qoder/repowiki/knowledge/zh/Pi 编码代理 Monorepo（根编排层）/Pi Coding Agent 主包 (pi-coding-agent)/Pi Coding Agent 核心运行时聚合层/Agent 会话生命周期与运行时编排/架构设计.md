模块由三层组成：
- `agent-session.ts`：定义 `AgentSession` 类及其事件类型、配置接口，封装 agent 状态访问、事件订阅、模型/思维级别管理、compaction（手动/自动/overflow）、Bash 执行、分支与工具注册、扩展钩子（before/after tool call、turn_end、boundary）等核心行为，是交互/打印/RPC 三种运行模式共享的抽象。
- `agent-session-services.ts`：提供 cwd 绑定的服务工厂 `createAgentSessionServices`（构造 ModelRuntime、SettingsManager、DefaultResourceLoader 并应用扩展 flag/provider/virtual-model 注册）与 `createAgentSessionFromServices`（把已就绪服务注入到 `createAgentSession`），将“进程级基础设施”与“会话级实例”解耦。
- `agent-session-runtime.ts`：`AgentSessionRuntime` 持有当前 `AgentSession` + `AgentSessionServices`，通过闭包持有的 `CreateAgentSessionRuntimeFactory` 在 `/new`、`/resume`、`/fork`、`importFromJsonl` 时先 teardown 旧 runtime（abort → session_shutdown → dispose），再重建新 runtime 并通过 `apply` 替换；同时暴露 `switchSession`、`newSession`、`fork`、`importFromJsonl`、`dispose` 等面向宿主的生命周期 API，并在切换前触发 `session_before_switch` / `session_before_fork` 扩展钩子以支持取消。
依赖方向单向：runtime → services → AgentSession → 各 core 子系统（compaction、extensions、tools、session-manager、model-runtime 等）。
