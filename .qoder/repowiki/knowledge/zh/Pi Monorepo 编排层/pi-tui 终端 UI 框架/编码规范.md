- UI 组件统一实现 `Component` 接口（render/handleInput/handleMouse/invalidate），并通过 `dispatchMouseEvent` 将鼠标事件向下转发给子节点。
- 组件内部维护私有缓存字段并在 `invalidate()` 中失效，避免每帧重复分配字符串对象以提升差分比较性能。
- 原生能力通过 `native-platform.ts` 的 `getNativePlatformHelper()` / `getNativeClipboard()` 懒加载，仅在首次调用时 `createRequire` 对应 `.node` 并缓存结果。
- 公共 API 集中在 `src/index.ts` 中按功能域分组 re-export，类型与实现分离但统一从该入口暴露。
- 测试文件以 `<feature>.test.ts` 命名放在 `test/` 根目录，借助 Node 内置 `--test` 运行器直接执行。
