模块以 `src/index.ts` 为单一公共入口，按职责划分为若干子层：
- 核心运行时：`tui.ts` 定义 `Component` / `Focusable` 接口、`dispatchMouseEvent` 事件冒泡机制、`TUI` 主循环；`tui-main-screen.ts`、`tui-alt-screen.ts` 分别管理主屏与备用全屏（OSC 7501 program-status）。
- 布局与组件：`layout.ts` + `layout-node.ts` 实现弹性布局树；`components/` 下每个文件是一个实现 `Component` 的 UI 控件（Box/VStack/HStack/ScrollView/Editor/Input/Markdown/Image/SelectList/SettingsList/Text/TruncatedText/Spacer/MouseRegion/Locator 等），通过容器组合形成 UI 树。
- 输入子系统：`keys.ts` 解析 Kitty/SGR 协议键码，`keybindings.ts` 维护可配置的 KeybindingDefinition 映射，`stdin-buffer.ts` 做批量输入拆分，`word-navigation.ts`、`fuzzy.ts`、`autocomplete.ts` 提供编辑辅助。
- 渲染与色彩：`colors.ts` 在 RGB/Oklch/Okhsl 空间间转换，`terminal-colors.ts` 解析终端 DA1 报告，`terminal-image.ts` 封装 Kitty/iTerm2 图像协议，`utils.ts` 提供 ANSI 序列处理与可见宽度计算。
- 原生桥接：`native-platform.ts` 通过 `createRequire` 动态加载 `native/<platform>/prebuilds/<platform>-<arch>/<platform>-platform[-x11].node`，暴露 `NativeClipboard` 接口（getText/getImage/getFilePaths/setText），Linux 走 XCB/X11，macOS 用 Objective-C，Windows 用 Win32 API，三者共享 `clipboard.h` 与 `napi.h` 头文件。
依赖方向单向：components → tui → keys/terminal-* → native-platform，测试位于 `test/` 目录，使用 Node 内置 `--test` 运行。
