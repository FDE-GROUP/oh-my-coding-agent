- 对外暴露的适配器契约以 interface 形式集中在 `index.ts`，具体实现（内存、noop）只 import 这些类型而不反向依赖。
- span 生命周期通过 `startSpan(options, callback)` 回调模式管理，finally 块中设置 `settled` 并计算 `endedMs`，确保异常路径也能正确结算。
- 所有外部可见的属性值在写入时经 `copyAttributes` 深拷贝过滤 `undefined`，防止调用方后续修改污染内部状态。
- schema 驱动的类型推导统一采用 `InferRequiredAndOptionalAttributes` / `ExactTelemetryAttributes` 组合，使 start 属性的 required 字段在编译期强制出现、end/event 属性可选且类型精确匹配。
- noop 对象一律通过 `Object.freeze` 创建并复用单例，避免每次调用分配新实例。
- carrier 使用私有命名空间键（如 `pi-memory-scope`、`pi-memory-span`、`pi-memory-trace`）存储上下文，避免与用户属性冲突。
