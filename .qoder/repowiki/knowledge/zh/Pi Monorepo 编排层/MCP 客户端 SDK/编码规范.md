- 对外 API 通过 `src/index.ts` 集中 re-export，内部模块只导出类型或实现，不直接对外暴露。
- 传输层统一实现 `McpTransport` 接口并由 `TransportEvents` 基类管理 onMessage/onError/onClose 监听器集合。
- JSON-RPC 消息在发送前经 `isJsonRpc*` 守卫函数校验，错误统一包装为 `McpError` 并附带 `JSON_RPC_ERROR_CODES`。
- 配置解析采用返回联合类型的校验函数（如 `validateMcpServerConfig` 返回 `{kind:'stdio'|'http'|'invalid'}`），将未知字段保留给调用方二次校验。
- 异步资源生命周期通过返回的 dispose 函数（如 `onNotification`、`setRequestHandler`、transport listener 注册）进行显式释放。
- OAuth 相关错误集中在 `errors.ts` 中定义为具名 Error 子类（`OAuthError`、`McpAuthRequiredError` 等），便于上层区分处理。
