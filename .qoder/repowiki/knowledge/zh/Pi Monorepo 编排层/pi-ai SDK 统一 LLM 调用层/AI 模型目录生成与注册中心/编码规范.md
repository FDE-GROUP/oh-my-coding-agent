- Provider 定义通过 `defineProvider({ id, models?, images?, classifiers?, compat?, finalize?, finalizeAll? })` 暴露，新增 provider 后需在 `providers/index.ts` 的 `PROVIDERS` 数组中注册。
- 跨 provider 的通用修正逻辑集中在 `families/`（如 anthropic/deepseek/openai 家族规则）和 `reasoning.ts`，由 `buildCatalog` 在 `finalize` 之前统一应用，provider 自身的 `finalize` 用于覆盖共享规则。
- 上游模型数据通过 `modelsDevModels(ctx, sourceProvider, options)` 适配器映射为 `Model<TApi>`，再经 `recordReasoning` 回写至 context 供共享 reasoning 规则消费。
- 生成产物采用 staging 目录 + `renameSync` 原子替换策略，失败时通过 `restoreGeneratedCatalog` 回调恢复 `.models.ts` 与 `models.generated.ts` 旧版本。
- JSON 模型数据按 provider 拆分为 `src/providers/data/<id>.json`，并通过 `MODEL_DATA_MANIFEST_FILE` manifest 记录结构指纹，由 `validateModelDataDirectory` 校验一致性。
