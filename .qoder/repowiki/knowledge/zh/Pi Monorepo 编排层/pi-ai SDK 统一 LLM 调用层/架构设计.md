包以 `src/index.ts`（sdk_surface）为公共入口，向上导出 `Provider`/`Model` 抽象；向下由四层协作：
- `api_adapters`：按厂商实现流式消息/工具/推理等协议适配，被各 provider 通过 `create*Api` 工厂复用。
- `providers`：每个厂商一个 `<provider>.ts` + `<provider>.models.ts`，声明 `ProviderDefinition` 并注册到 `all.ts`，同时产出 `src/providers/data/*.json` 供 catalog 消费。
- `model_catalog_generation`：读取各 provider 的 JSON 清单与外部 sources，经 `catalog/generate.ts` 合成运行时可用的 `models.generated.ts` 与类型化 catalog。
- `auth_oauth`：在 `resolve()` 中按 provider 选择 API Key 或 OAuth 流程，结果注入到 api adapter 的请求头。
- `shared_utils`：重试、事件流、JSON 解析、错误归一化等被 api_adapters 与 providers 共同依赖。
构建链路：`npm run generate-models` → `generate-model-catalog` → `tsc -p tsconfig.build.json` → 复制 `src/providers/data` 到 dist，最终发布 `dist/providers/data/*.json` 作为离线模型清单。
