- Provider OAuth 实现统一导出名为 `*OAuth` 的 `OAuthAuth` 对象，由 `load.ts` 通过约定名称动态 import 或从 `bundledLoaders` 中取用。
- 所有异步操作接受可选的 `AbortSignal`，并通过 `operationSignal`/`raceWithAbortSignal` 包装，确保登录、刷新、回调等待可被上层取消。
- 对凭证存储的所有写操作（刷新、登录、登出）都走 `CredentialStore.modify` 提供的序列化写入路径，保证并发请求不会重复刷新同一 token。
- 错误统一包装为 `ModelsError` 并携带语义化的 code（如 `"auth"`、`"oauth"`），而非直接抛出原始异常。
- OAuth 刷新采用「乐观过期判断 + `modify` 内权威检查」的双重检查锁模式，默认阈值设为 expires - 5 分钟。
- Node.js 专属能力（`node:http`、`node:crypto`）集中在 `oauth/callback-server.ts` 与 `oauth/pkce.ts`，并通过 `load.ts` 的动态 import 隔离，使浏览器 bundle 不包含这些依赖。
