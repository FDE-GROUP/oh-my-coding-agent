本模块是 `packages/ai/src` 下的纯工具层，不暴露业务 API，仅被上层 provider、runtime、agent 等模块引用。

- 可重试请求层：`retry.ts` 定义 `RetryPolicy` / `RetryCallbacks` 与基于指数退避（`baseDelayMs * 2^(attempt-1)`）的 `retryAssistantCall`，并通过 `NON_RETRYABLE_PROVIDER_LIMIT_ERROR_PATTERN` 与 `RETRYABLE_PROVIDER_ERROR_PATTERN` 正则表对 `AssistantMessage.errorMessage` 做瞬态/限额分类；`provider-retry.ts` 则实现与 OpenAI/Anthropic SDK 对齐的 HTTP 级重试 `retryProviderRequest`，支持 `x-should-retry`、`retry-after-ms`、`retry-after` 头与 `AbortSignal` 中断。
- 流式数据层：`streaming-json.ts` 提供增量容错 JSON 解析器 `StreamingJsonParser`（带 `snapshot()` 不可变快照与 `append()` 变更 diff），并封装 `ToolCallArgumentsStream` 用于流式 tool-call 参数；`event-stream.ts` 提供泛型 `EventStream<T,R>` 与 `AssistantMessageEventStream`（自动计时）。
- 错误处理层：`error-body.ts` 通过探测 Mistral/openai/@google/genai/Bedrock 多种 SDK 字段形状统一提取 status/body/message，输出 `NormalizedProviderError`；`models-error.ts` 提供结构化 `ModelsError`。
- 模型与运行时辅助：`model-operations.ts` 提供 `getModelType` / `isModelType` / `assert*Model` 等运行时类型收窄；`provider-env.ts` 在 Bun sandbox 下回退读取 `/proc/self/environ`；`abort-signals.ts`、`abort.ts`、`sleep.ts`、`uuid.ts`、`hash.ts`、`diagnostics.ts`、`version.ts`、`identity.ts`、`headers.ts`、`overflow.ts`、`sanitize-unicode.ts`、`string-enum.ts`、`text.ts`、`transcript.ts`、`validation.ts`、`estimate.ts`、`json-parse.ts`、`node-http-proxy.ts`、`oauth-page.ts`、`openrouter-cost.ts` 等为各自职责的单文件工具。

依赖方向单向向外：utils 仅依赖 `../types.ts` 与同目录其他 utils，不被同级其它 utils 反向依赖（除 `streaming-json.ts` → `json-parse.ts`、`model-operations.ts` → `models-error.ts` 等小范围组合）。
