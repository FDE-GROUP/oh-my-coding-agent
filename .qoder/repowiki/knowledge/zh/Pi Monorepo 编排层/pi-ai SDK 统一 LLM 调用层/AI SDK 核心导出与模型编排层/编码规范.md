- 所有异步操作统一通过 `operationSignal(options?.signal)` 包装并配合 `raceWithAbortSignal` 包裹执行体，确保调用方传入的 AbortSignal 可中断刷新、鉴权与请求流程。
- Provider 的同步读取方法（如 `getModels`、`getAllModels`）在遍历中用 try/catch 包裹，对抛出异常的 provider 返回空结果而非向上抛出，体现 best-effort 容错策略。
- 对外 API 以 interface + class 实现分离：先声明 `Provider`/`Models`/`MutableModels` 等契约接口，再在文件末尾给出 `ModelsImpl` 实现，类型与实现解耦。
- 错误统一通过 `ModelsError` 构造，附带语义化的 code（如 "auth"、"provider"、"model_source"、"oauth"）与 cause 链，便于上层区分 OAuth 刷新失败与配置缺失。
- 可选能力通过可选属性表达（`refreshModels?`、`filterModels?`、`generateImages?`、`classify?`、`fetchDeferred?`），调用方用 `?.()` 安全访问，未实现的 provider 静默降级。
