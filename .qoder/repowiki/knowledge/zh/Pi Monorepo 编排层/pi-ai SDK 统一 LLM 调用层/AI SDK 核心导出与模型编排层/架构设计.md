本模块由三个文件组成清晰的职责分层：
- `index.ts` 是纯类型重导出的 barrel 文件，显式声明“仅 core、无 side effect”，不导出 provider 工厂、API 实现或 compat 运行时；它把 `./api/*` 的类型、`./auth/*`、`./models.ts`、`./providers/faux.ts`、`./session-resources.ts`、`./types.ts` 以及 `./utils/*` 工具统一重新导出，构成包的对外 API 边界。
- `models.ts` 定义 Provider / Models / MutableModels 接口族与 `ModelsImpl` 实现，是运行时编排核心：管理 provider 注册表、CredentialStore、ModelsStore、AuthContext，负责 OAuth 刷新、并发 refresh（按 provider 分代 + AbortController 取消）、可用模型过滤、鉴权解析（`resolveProviderAuth`）以及将请求委派给具体 provider 的 stream/fetchDeferred/generateImages/classify 等能力。
- `oauth.ts` 仅为编码扩展提供类型兼容入口，只 re-export `./compat/extension-oauth-types.ts` 中的 OAuth 相关类型，不含任何运行时逻辑。
依赖方向单向向外：本模块依赖 `./auth/*`、`./api/lazy.ts`、`./telemetry.ts`、`./utils/*` 和 `./types.ts`，不被这些子模块反向引用，保持 core 层的稳定性。
