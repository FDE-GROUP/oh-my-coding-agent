模块由三个职责清晰的文件组成：
- `sdk.ts` 是对外 SDK 入口，导出 `CreateAgentSessionOptions` / `CreateAgentSessionResult` 接口和 `createAgentSession` 工厂函数；内部组合 `ModelRuntime`、`SettingsManager`、`SessionManager`、`DefaultResourceLoader`、`CacheWarmer`、工具工厂等子模块，组装底层 `@earendil-works/pi-agent-core` 的 `Agent`，并通过 `streamSimple` + `markRuntimeStreamFunction` 注入 provider 流式能力，同时通过 extension runner 钩子 (`before_provider_headers` / `before_provider_request` / `after_provider_response` / `provider_stream_event`) 暴露可观测点。
- `pi-manifest.ts` 提供 `PiManifest` 接口与 `readPiManifest` 解析器，从包的 `package.json` 中读取 `pi.extensions/skills/prompts/themes/changelogPath` 字段，用于扩展/技能发现。
- `pi-ai-schemas.ts` 将 `@earendil-works/pi-ai` 导出的 JSON Schema（ProviderCompat、ModelCost、ThinkingLevelMap 等）通过 `Type.Unsafe` 重新包装为 TypeBox schema，供本项目自己的 settings/models 配置校验复用。
依赖方向单向向外：本模块被上层 agent-session-runtime 等消费，自身仅依赖 core 内部其他子模块与外部 pi-ai/pi-agent-core。
