- 所有涉及磁盘写入的临界区都通过 `proper-lockfile` 加锁，同步路径用 `lockSync`+忙等待，异步路径用 `lock(..., { stale })`+指数退避并重试 EPERM/ELOCKED。
- JSON 文件读写前统一调用 `stripBom` 处理 BOM，并在解析后校验值类型，失败时抛出带文件名/键名的错误消息。
- 对外暴露的 `CredentialStore` 实现均接受可选的 `AuthOperationOptions`，并在关键分支调用 `options?.signal?.throwIfAborted()` 响应取消信号。
- 可写存储类通过构造函数注入后端（如 `AuthStorage` 注入 `AuthStorageBackend`），并提供静态工厂方法（`create`/`fromStorage`/`inMemory`）构造不同实现。
