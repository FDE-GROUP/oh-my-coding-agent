- 每个工具以 `createXxxToolDefinition(cwd, options)` 工厂函数暴露 ToolDefinition，并通过同名 `wrapToolDefinition(...)` 包装器导出 `createXxxTool` 便捷函数。
- I/O 能力通过可选的 `operations` 配置注入（ReadOperations/WriteOperations/EditOperations），默认值使用 Node fs 实现，便于扩展层替换为远程后端。
- 所有工具声明 `constrainedSampling: { type: "json_schema", strict: "prefer" }` 以启用结构化输出约束。
- write 与 edit 工具将实际文件操作包裹在 `withFileMutationQueue(absolutePath, ...)` 中以按路径串行化，并在每次 await 后通过 `throwIfAborted()` 检查 AbortSignal。
- 每个工具导出一个 `xxxToolSystemPromptContribution` 常量对象（含 snippet 与 guidelines），并在 ToolDefinition 中通过展开 `[...guidelines]` 注入系统提示词。
- 工具参数 schema 统一用 TypeBox `Type.Object({...})` 定义，并通过 `Static<typeof schema>` 推导出对应的 TypeScript 输入类型。
