本模块由三个相互独立的基础设施单元组成，均被 core/tools 下的具体工具消费：
- file-mutation-queue.ts：通过全局 `fileMutationQueues` Map（以 `realpath` 解析后的绝对路径为 key）维护每个文件的 Promise 链，并用 `registrationQueue` 串行化注册过程，使同一文件的多次写入按 FIFO 执行，不同文件仍并行。
- output-accumulator.ts：`OutputAccumulator` 类在内存中用 `Buffer[]` + `tailText` 滚动窗口保存最近输出，超过阈值时通过 `createOutputFileStream` 降级到临时 `.log` 文件；对外暴露 `append/finish/snapshot/readFullOutput/closeTempFile` 生命周期，并复用同目录的 `truncate.ts` 做行/字节双限截断。
- tool-definition-wrapper.ts：在扩展侧的 `ToolDefinition`（含 TypeBox 参数 schema、prompt 元数据、渲染器）与核心运行时要求的 `AgentTool` 之间提供双向适配器——`wrapToolDefinition/wrapToolDefinitions` 将扩展定义包装成 `AgentTool`，`createToolDefinitionFromAgentTool` 反向合成最小定义，供 `AgentSession` 统一以 definition-first 方式注册。
依赖方向单向向外：本模块仅依赖 node:fs、node:path、上层 utils/output-files 和 truncate，不被其他 core 子模块反向依赖。
