- Shell 工具通过 `createShellToolDefinition(cwd, ShellToolConfig, options)` 工厂复用，不同 shell 仅需提供 name/label/prompt/tempFilePrefix 等配置对象。
- 命令执行后端通过 `BashOperations` 接口解耦，默认使用 `createLocalShellOperations`，扩展可注入自定义 operations（如 SSH 远程执行）。
- 工具定义经 `wrapToolDefinition` 包装后，再手动 assign promptSnippet/promptGuidelines 到返回对象以补充元数据。
- 编辑操作先对 oldText/newText 做 LF 归一化，再用 `fuzzyFindText` 精确→模糊两级匹配，并在模糊模式下通过 `applyReplacementsPreservingUnchangedLines` 将变更叠加回原始内容以保持未改动行字节不变。
- 错误信息根据 edits 数量区分单条与多条场景，分别构造 getNotFoundError/getDuplicateError/getEmptyOldTextError/getNoChangeError 等辅助函数返回可读提示。
