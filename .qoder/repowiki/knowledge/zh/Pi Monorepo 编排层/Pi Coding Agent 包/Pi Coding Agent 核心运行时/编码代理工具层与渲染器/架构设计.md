本模块是 coding-agent 核心工具层的装配中心：
- 每个工具（read/write/edit/find/grep/ls/bash/powershell）遵循 `createXxxTool` + `createXxxToolDefinition` 双工厂模式，分别产出运行时可调用的 `AgentTool` 和供扩展系统注册的 `ToolDefinition`。
- `index.ts` 集中维护 `ToolName` 联合类型、`allToolNames` 白名单以及 `createTool` / `createToolDefinition` 分派器，并提供 `createCodingTools`（读写+编辑）、`createReadOnlyTools`（只读检索）、`createAllTools` 三种预置集合，由上层按沙箱能力选择注入。
- 横切基础设施集中在同目录：`file-mutation-queue.ts` 按路径串行化所有写操作以消除并发写入竞争；`output-accumulator.ts` 提供带字节/行数截断的流式输出累积；`truncate.ts` 被 read/grep/bash 共享；`tool-definition-wrapper.ts` 在 ToolDefinition 与 AgentTool 之间做双向适配。
- `renderers/` 子目录将 bash/edit/read/write/grep/find/ls 的 TUI 展示逻辑与工具实现解耦，仅当需要渲染时加载，从而减小无头进程的模块体积。
- 工具间不直接互相调用，而是通过共享的基础设施（队列、截断、包装器）与统一的 `ToolName` 枚举协作。
