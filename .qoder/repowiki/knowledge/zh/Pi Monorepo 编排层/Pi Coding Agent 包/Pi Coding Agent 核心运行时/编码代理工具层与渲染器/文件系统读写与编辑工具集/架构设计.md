本模块由三个并列的 ToolDefinition 实现组成：read.ts（读取文本或图片）、write.ts（创建/覆盖文件）、edit.ts（基于 oldText/newText 的精确替换）。每个工具遵循统一工厂模式：定义 TypeBox schema → 暴露 `createXxxToolDefinition(cwd, options)` 返回标准 ToolDefinition → 再经 `wrapToolDefinition` 包装为 `TypeBoxAgentTool`。

- I/O 抽象：通过 `ReadOperations` / `WriteOperations` / `EditOperations` 接口注入默认本地 fs 实现，允许扩展层替换为 SSH 等远程后端。
- 路径解析：读工具走 `resolveReadPathAsync`（含安全校验），写/编辑工具走 `resolveToCwd`。
- 并发控制：write 与 edit 通过 `withFileMutationQueue` 对同一绝对路径串行化写入，避免并发冲突；abort 通过 `signal.aborted` 在每次 await 后检查而非直接 reject。
- 渲染：各工具从同级 `renderers/read.ts`、`renderers/write.ts`、`renderers/edit.ts` 解构出 renderers 并展开到 ToolDefinition 中。
- 提示词贡献：每个工具导出 `xxxToolSystemPromptContribution`（snippet + guidelines）供系统提示词聚合。
- 依赖方向：仅向上依赖 `../extensions/types.ts` 的 ExtensionContext/ToolDefinition，向下依赖 utils/image-process、utils/mime、utils/text 以及同级的 path-utils、truncate、edit-diff、file-mutation-queue。
