- 每个工具通过 `createXxxToolDefinition` 返回 `ToolDefinition`，再经 `wrapToolDefinition` 包装成 `TypeBoxAgentTool`，并提供同名 `createXxxTool` 工厂函数。
- 工具参数 schema 使用 TypeBox `Type.Object` 定义，并通过 `Static<typeof schema>` 导出输入类型。
- 通过 `operations` 选项配合 `XxxOperations` 接口实现后端可插拔，默认值以 `defaultXxxOperations` 对象提供本地实现。
- 所有异步执行体包裹 AbortSignal 监听，收到 abort 时清理子进程并拒绝 Promise，错误统一表述为 `"Operation aborted"`。
- 输出统一经 `truncateHead` 按 `DEFAULT_MAX_BYTES` 字节上限截断，并在末尾追加 `[...] limit reached` 形式的 notices 字符串，同时在 `details` 中记录截断元数据。
- 工具描述与 `promptSnippet` 来自同名的 `xxxToolSystemPromptContribution` 常量，保持对 LLM 的系统提示一致。
