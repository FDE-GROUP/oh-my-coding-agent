- 对外能力通过 interface（如 EventBus、PackageManager、ResourceLoader、NestedToolCallHost）暴露契约，具体实现以 Default* 前缀类提供，便于测试替换。
- 异步副作用（事件处理器、stdout 写入、子进程 kill）统一包裹 try/catch 或返回失败而非抛出，避免宿主崩溃。
- 路径与资源去重用 `getResourcePathKey` / `canonicalizePath` / `getPathComparisonKey` 组合，合成路径（builtin:/<>）走分支逻辑，真实路径走 realpath 比较。
- 可观测性（timing、cache stats、usage totals、telemetry）全部通过纯函数对 SessionEntry/Usage 数据做无副作用扫描，不持有外部状态。
- 长生命周期对象（CacheWarmer、NestedToolCallRunner、DefaultResourceLoader）通过构造函数注入依赖（models、sessionManager、settingsManager），并在 stop/clear/takeRecord 中显式释放定时器与 AbortController。
