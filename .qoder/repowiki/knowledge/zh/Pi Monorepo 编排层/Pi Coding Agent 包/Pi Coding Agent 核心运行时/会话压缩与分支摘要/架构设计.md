模块按职责拆分为三个文件并通过 `index.ts` 统一导出：
- `compaction.ts`：核心入口，定义 `CompactionSettings`/`CompactionPreparation`/`CompactionResult` 等类型，实现 token 估算（`estimateTokens`、`calculateContextTokens`）、切点查找（`findCutPoint`、`findProjectedCutPoint`）、准备阶段（`prepareCompaction`）以及主压缩函数 `compact`；所有对 LLM 的调用统一走 `completeSummarization`（封装 `retryAssistantCall`），并内置初始/增量两种结构化 prompt。
- `branch-summarization.ts`：处理树形会话中从旧叶子回到新位置时生成被放弃分支的摘要，依赖 `ReadonlySessionManager.getBranch/getEntry` 回溯到共同祖先，复用 `compaction.ts` 的 `completeSummarization` 与 `utils.ts` 的文件操作追踪。
- `utils.ts`：纯工具层，提供 `FileOperations` 集合、从 tool call 提取文件读写痕迹（`extractFileOpsFromMessage`、`computeFileLists`、`formatFileOperations`）以及将 LLM 消息序列化为文本的 `serializeConversation`。

依赖方向单向：`branch-summarization.ts` → `compaction.ts` → `utils.ts`；对外仅通过 `index.ts` 暴露 API，I/O（session-manager、tool 执行）由上层 session-manager 负责，本模块保持纯函数风格。
