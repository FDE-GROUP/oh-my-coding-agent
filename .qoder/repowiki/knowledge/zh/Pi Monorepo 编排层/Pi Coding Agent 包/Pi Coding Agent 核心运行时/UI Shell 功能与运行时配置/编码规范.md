- 资源加载器（prompt-templates、skills）统一返回 `{ templates/skills, diagnostics }` 结构体，将解析错误以 `ResourceDiagnostic` 警告形式累积而非抛错。
- 外部可配置项（快捷键、prompt 模板、skill）均从 agentDir 与 project configDir 两个位置扫描，并通过 `createSyntheticSourceInfo` 标注 source/scope/baseDir 以便诊断定位。
- 对用户输入或可能包含敏感信息的值进行脱敏后再序列化：URL 走 `redactUrl`，对象字段走 `redactJsonValue`，settings 单独剥离 trackingId/deviceId。
- 跨平台行为通过 `useWindowsKeybindings()` / `isWslEnvironment()` 等检测函数集中判断，避免在多处散落 `process.platform === 'win32'` 条件。
- 长生命周期服务类（`FooterDataProvider`、`KeybindingsManager`）暴露 `dispose`/`reload` 方法，内部使用定时器 + 标志位（`refreshInFlight`/`refreshPending`/`disposed`）防抖与竞态保护。
- 对外暴露的类型通过 TypeScript 声明合并扩展上游包（`CustomAgentMessages`、`Keybindings`），而不是复制上游接口。
