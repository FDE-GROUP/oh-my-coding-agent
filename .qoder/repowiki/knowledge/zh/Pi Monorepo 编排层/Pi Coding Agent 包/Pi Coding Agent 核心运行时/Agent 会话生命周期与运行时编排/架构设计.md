本模块由三层组成，依赖方向自上而下：
- `agent-session.ts`：定义 `AgentSession` 类及其事件类型（`AgentSessionEvent`）、配置（`AgentSessionConfig`）和工具注册表，是跨交互/打印/RPC 三种运行模式共享的核心抽象，负责状态访问、事件订阅、模型与 thinking level 管理、compaction、bash 执行、会话分支与扩展钩子。
- `agent-session-services.ts`：按 cwd 构建一组可重建的运行时基础设施（`ModelRuntime`、`SettingsManager`、`ResourceLoader`、`DefaultResourceLoader`），暴露 `createAgentSessionServices` 与 `createAgentSessionFromServices`，将服务创建与具体 session 构造解耦，使调用方可先针对目标 cwd 解析 model/tools 再建 session。
- `agent-session-runtime.ts`：持有当前 `AgentSession` + `AgentSessionServices` 对，通过闭包保存 `CreateAgentSessionRuntimeFactory`，对外暴露 `switchSession/newSession/fork/importFromJsonl/dispose` 等生命周期方法；每次切换都走 `teardownCurrent` → 调用工厂重建 → `apply` 替换内部状态的统一流程，并通过 `session_before_switch` / `session_before_fork` / `session_shutdown` 扩展点让扩展参与切换前拦截与清理。

依赖方向严格单向：runtime → services → sdk(`createAgentSession`) → agent-session；services 不反向依赖 runtime，从而允许在 cwd 变化时仅重建 services 而不销毁整个 session 对象。
