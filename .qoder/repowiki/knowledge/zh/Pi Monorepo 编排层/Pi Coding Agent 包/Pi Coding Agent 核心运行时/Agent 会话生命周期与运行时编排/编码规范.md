- 会话生命周期变更（new/resume/fork/import）统一先触发扩展钩子（`session_before_switch` / `session_before_fork`），若返回 `cancel: true` 则直接中止，否则进入 `teardownCurrent` → 重建 → `apply` 的标准流程。
- cwd 相关的基础设施（modelRuntime、settingsManager、resourceLoader）被封装进 `AgentSessionServices` 接口，并在 cwd 变化时整体重建，而非在现有实例上原地修改。
- 非致命错误以结构化 `AgentSessionRuntimeDiagnostic`（含 type/message）收集并返回给上层，而不是直接抛出或打印，由应用层决定展示策略。
- 对外暴露的入口函数（如 `createAgentSessionServices`、`createAgentSessionFromServices`、`createAgentSessionRuntime`）采用 options 对象参数，并将可选字段赋予默认值，保持构造路径一致。
