- 所有可序列化实体采用带字面量 `type` 字段的 discriminated union（如 `type: 'session' | 'message' | 'compaction' ...`），解析时按 `type` 分支处理。
- 对旧版会话文件通过 `migrateV1ToV2` / `migrateV2ToV3` 等迁移函数原地修改 entries 并递增 header.version，在 `_loadEntries` 中统一调用 `migrateToCurrentVersion`。
- I/O 操作使用 `openSync` + `readSync` + `StringDecoder` 分块读取并按换行符切分 JSONL 行，而非一次性 `readFileSync`，以支持超大会话文件。
- 面向测试的辅助函数（如 `parseSessionEntries`、`loadEntriesFromFile`、`migrateSessionEntries`）显式 `export` 以便单元测试直接调用。
- 错误对象继承 `Error` 并设置自定义 `name` 字段（如 `SessionHeaderScanLimitError`、`MissingSessionCwdError`），便于上层区分异常类型。
