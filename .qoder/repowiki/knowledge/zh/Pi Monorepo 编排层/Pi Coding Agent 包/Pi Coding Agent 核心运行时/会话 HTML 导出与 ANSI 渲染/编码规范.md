- 对外 API 同时接受字符串或 `ExportOptions` 对象作为 options 参数，并在入口处做类型归一化。
- 模板注入采用 `{{PLACEHOLDER}}` 占位符 + `String.prototype.replace` 的字符串替换模式，依次替换 CSS/JS/SESSION_DATA/vendor JS 等片段。
- 自定义工具渲染通过 `ToolHtmlRenderer` 接口解耦，renderCall/renderResult 返回 `undefined` 表示无自定义渲染，由调用方回退到结构化结果展示。
- ANSI 文本转 HTML 时先对 `& < > " '` 进行 HTML 转义，再将 SGR 样式编译为内联 `style` 属性并包裹在 `<span>` 中。
