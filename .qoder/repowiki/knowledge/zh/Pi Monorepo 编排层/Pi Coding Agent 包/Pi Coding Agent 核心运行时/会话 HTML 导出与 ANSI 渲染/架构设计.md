模块以 `index.ts` 为入口，对外暴露 `exportSessionToHtml`（基于 `SessionManager` + `AgentState`）和 `exportFromFile`（仅读取 `.jsonl` 文件）两个导出函数；内部通过 `generateHtml` 统一组装模板：从 `getExportTemplateDir()` 读取 `template.html` / `template.css` / `template.js` 及 `vendor/` 下的 `marked.min.js`、`marked-cjk-friendly.min.js`、`highlight.min.js`，将主题变量、CSS、JS、Base64 编码的 `SessionData` 注入后写入磁盘。

- 主题系统：`generateThemeVars` 调用 `getResolvedThemeColors` / `getThemeExportColors` 生成 CSS 自定义属性，并通过 `deriveExportColors` 由 `userMessageBg` 派生页面/卡片/信息区背景色。
- 工具渲染分层：`tool-renderer.ts` 实现 `ToolHtmlRenderer` 接口，通过 `getToolRenderers` 查找扩展工具的 `renderCall`/`renderResult`，用 TUI `Component.render(width)` 输出 ANSI 行，再经 `ansi-to-html.ts` 转为内联样式 HTML；`index.ts` 中 `TEMPLATE_RENDERED_TOOLS` 白名单（bash/read/write/edit/ls）走模板直出，其余工具走此预渲染路径。
- ANSI→HTML：`ansi-to-html.ts` 独立实现 SGR 解析器，支持标准/明亮前景背景色、256 色盘、RGB 真彩及 bold/dim/italic/underline/reset，输出 `<span style=...>` 包裹的 HTML。
- 依赖方向：本模块向上依赖 `../session-manager`、`../../modes/interactive/theme/theme`、`../../config`、`../extensions/types`，不反向被 extensions 直接引用，仅通过 `ToolHtmlRenderer` 接口被上层装配。
