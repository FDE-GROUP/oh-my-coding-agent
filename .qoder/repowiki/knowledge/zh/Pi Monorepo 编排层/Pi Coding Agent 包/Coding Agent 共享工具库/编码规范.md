- 对外暴露的异步工具函数统一返回 Promise，并在失败时抛出 Error（如 `fetchWithRetry`、`ensureTool`、`resizeImageInProcess`），由调用方决定错误处理策略。
- 跨平台差异通过 `process.platform === 'win32'` 分支处理，Windows 路径使用 `path.win32.join` / `SystemRoot` 等环境变量定位系统可执行文件（见 `shell.ts`、`tools-manager.ts`）。
- 需要阻塞式 I/O 或 WASM 调用的场景优先放在 `node:worker_threads` 中执行（`image-resize.ts` → `image-resize-worker.ts`），避免阻塞 TUI 事件循环。
- HTTP 请求统一走 `management-http.ts` 的 `fetchWithRetry`，通过 `RETRYABLE_STATUS_CODES` 白名单和 `AbortSignal.any` 组合 parent/timeout/attempt 信号实现可取消的重试。
- 外部二进制工具通过 `TOOLS` 配置表声明式注册（名称、仓库、tagPrefix、getAssetName），新增工具只需追加条目并由 `ensureTool` 统一处理发现、下载、解压流程。
- 面向用户的错误消息通过可选的 `onStatus` 回调以 `{ type: 'info' | 'warning', message }` 结构上报，而非直接 console.log（见 `tools-manager.ensureTool`）。
