- CLI 子命令以独立文件放在 src/cli/ 下，并通过统一入口注册到主 CLI 分发器。
- 运行模式（interactive/rpc/print）在 src/modes/ 下各自实现，统一通过 AgentSessionRuntime 驱动会话。
- 扩展以 src/extensions/<name>/ 目录形式组织，包含 index.ts 入口及可选 ui/lazy 变体，由 core_agent_runtime 的 extensions 子系统加载。
- 配置项使用 TypeScript 类型定义配合 JSON Schema 校验，Schema 由脚本自动生成而非手写。
- 跨平台差异通过 shared/utils 下的工具函数封装（如 child-process、shell、git、clipboard），避免在各层直接调用系统 API。
