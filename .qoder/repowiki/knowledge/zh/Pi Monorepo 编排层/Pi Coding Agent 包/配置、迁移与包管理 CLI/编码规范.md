- 路径解析函数统一以 `get*Path()` / `get*Dir()` 命名，并在开头优先检查 `process.env.PI_*` 环境变量（如 `PI_PACKAGE_DIR`、`PI_SELF_UPDATE_COMMAND`、`PI_MANAGED_INSTALL_ROOT`）以允许覆盖。
- JSON 文件读取一律先经 `stripBom` 处理后再 `JSON.parse`，避免 BOM 导致的解析失败。
- 迁移函数采用幂等设计：先 `existsSync` 检查目标状态，存在则直接返回；写入新文件时使用 `{ mode: 0o600 }` 限制权限，失败路径统一 try/catch 忽略。
- CLI 参数解析将短选项与长选项映射到布尔标志位，无效选项/冲突选项/缺失值分别记录到 `invalidOption`/`conflictingOptions`/`missingOptionValue` 字段后统一在入口处打印 usage 并设置 `process.exitCode = 1`。
- 自更新命令通过 `SelfUpdateCommandStep` + `makeSelfUpdateCommand` 组合出可显示的 `display` 字符串，并将 uninstall 步骤作为前置 step 拼接，使错误消息能提示回滚方式。
- 对外导出的 CLI 处理器 (`handleConfigCommand`、`handlePackageCommand`) 均以 `(args, runtimeOptions?) => Promise<boolean>` 签名返回是否已消费该命令，便于上层路由分派。
