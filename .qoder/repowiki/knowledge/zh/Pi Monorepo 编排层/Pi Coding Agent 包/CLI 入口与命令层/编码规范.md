- CLI 参数解析统一返回包含 `messages`、`fileArgs`、`unknownFlags`、`diagnostics` 的 `Args` 对象，错误以 `{type:'warning'|'error', message}` 形式追加到 diagnostics 而非抛错。
- 交互式对话框通过 `createStartupTui` 创建 `TuiMainScreen`，用 `new Promise` 包装组件回调，并在 settled 后调用 `clearStartupTui` + `ui.stop()` 释放资源。
- 子命令采用 kind 枚举 + 解析函数（如 `parseAuthCommand`）+ 校验函数（如 `validateAuthCommandArgs`）三段式拆分，未知选项抛出专用 Error 子类（如 `AuthCommandError`）。
- 文件参数以 `@` 前缀识别，经 `resolveReadPath` + `resolve` 展开后区分 MIME 类型走图片处理或纯文本读取路径。
