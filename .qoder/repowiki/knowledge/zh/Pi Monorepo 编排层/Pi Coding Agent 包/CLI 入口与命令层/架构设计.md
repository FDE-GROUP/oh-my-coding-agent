模块按职责拆分为四个层次：
- 参数与帮助：`args.ts` 实现 `parseArgs`/`printHelp`，将原始 argv 解析为统一的 `Args` 结构体，并收集 unknownFlags 供扩展注入；`setup.ts` 在进程启动时设置 process.title、环境变量并初始化 HTTP dispatcher。
- 子命令路由：`auth-command.ts` 定义 `AuthCommandKind`（check/api_key/bearer_token）及 `parseAuthCommand`/`validateAuthCommandArgs`，由 `auth-login.ts`、`auth-logout.ts`、`auth-check.ts`、`auth-terminal.ts`、`credential-print.ts` 分别实现具体逻辑。
- 交互式 TUI：`startup-ui.ts` 通过 `@earendil-works/pi-tui` 的 `TuiMainScreen` + `ProcessTerminal` 构建首次安装向导、选择器与输入框；`config-selector.ts`、`session-picker.ts`、`initial-message.ts`、`project-trust.ts` 复用同一套 TUI 组件封装各自的交互流程。
- 辅助工具：`file-processor.ts` 把 `@path` 参数展开为文本与图片附件；`list-models.ts`、`auth-check.ts` 等作为独立可复用的 CLI 功能单元。
依赖方向单向向外：本模块仅消费 `../core/*`、`../modes/interactive/*`、`../utils/*` 与外部包（chalk、pi-tui），不被业务模式反向依赖。
