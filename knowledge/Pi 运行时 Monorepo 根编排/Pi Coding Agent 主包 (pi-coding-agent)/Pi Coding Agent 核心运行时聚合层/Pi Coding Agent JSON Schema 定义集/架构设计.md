本模块是纯数据契约目录，不包含可执行代码，由 TypeScript 源码经 `npm run generate:schemas` 生成四个独立的 JSON Schema 文件：
- `settings.schema.json`：用户设置根对象，包含 transport、sessionShareDestination、compaction、retry、terminal、images、codemode、tuiMode 等配置域，使用 `$defs.ModelThinkingLevel` 复用枚举。
- `models.schema.json`：模型与 Provider 配置，顶层要求 `providers` 键，支持 provider 级 baseUrl/apiKey/oauth/headers/compat 以及 per-model 的 inputLimits/cost/promptCache/samplingParams 等，并通过 `$defs` 复用 ModelCost、ModelInputLimits、ProviderCompat 等复杂类型。
- `keybindings.schema.json`：TUI 快捷键映射，所有值引用统一的 `KeybindingValue`（字符串或字符串数组），通过正则限制修饰符组合与按键名。
- `theme.schema.json`：主题配色方案，要求 name/colors，colors 下严格列出 UI 语义色键（accent、border、md*、syntax*、thinking* 等）并复用 `ColorValue` 联合类型。

所有 schema 统一采用 `https://json-schema.org/draft/2020-12/schema`，$id 以 `https://pi.dev/schemas/` 命名空间发布，跨文件通过 `$ref` 在单个 schema 内部复用 $defs，schema 之间不互相引用，保持扁平契约边界。
