模块由三个文件组成清晰的职责分层：
- `radius.ts` 提供常量与工具（`RADIUS_PROVIDER_ID`、`ENV_RADIUS_GATEWAY`、`RADIUS_MCP_URL`、`getRadiusGatewayUrl()`），仅依赖 `@earendil-works/pi-ai/providers/radius-config`，作为所有其他文件的常量源。
- `mcp-servers.ts` 是核心层：在 `@earendil-works/pi-mcp` 的 `McpStdioServerConfig` / `McpHttpServerConfig` / `McpOAuthConfig` 之上叠加 pi 自有字段（`exposure`、`toolExposure`、`description`、`timeout`、`auth.provider`），通过 `validateMcpServerConfig` 完成别名解析、暴露策略校验与 HTTP auth 安全约束（非 loopback 必须 https）；同时导出 `McpServerRegistry` 类，供扩展通过 `pi.registerMcpServer()` 注册服务器并在变更时触发 `mcp_servers_change` 事件。
- `radius-mcp.ts` 是适配层：读取全局 `mcp.json`（`loadMcpConfig`），比较现有 entry 的 URL 与 `auth.provider`，生成 `RadiusMcpServerPlan`（`mcpPath` + `name` + `config`），用于增量写入或更新以让 Radius MCP 使用指定 provider 登录。
依赖方向单向：`radius-mcp.ts` → `radius.ts` + `mcp-servers.ts`，`mcp-servers.ts` 不反向引用 radius。
