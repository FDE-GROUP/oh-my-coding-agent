- 对外暴露的 CredentialStore 实现同时提供同步 `withLock` 与异步 `withLockAsync` 两套 API，后者接受 `AuthOperationOptions` 中的 AbortSignal 用于取消。
- 所有对 `auth.json` 的写操作统一通过 `AUTH_FILE_WRITE_OPTIONS`（utf-8、mode 0o600）写入，目录创建使用 mode 0o700，保证凭据文件权限隔离。
- JSON 文件读取一律先经 `stripBom` 去 BOM，再以对象结构校验后再 `as AuthStorageData` 强转，避免直接 `JSON.parse` 后直接使用。
- 用户可见的错误/提示文案集中在 `auth-guidance.ts` 中通过 `join(getDocsPath(), ...)` 拼接文档路径，避免在调用方硬编码相对路径。
- 项目信任决策遵循固定优先级链：`trustOverride` → extension `project_trust` 事件 → `trustStore.get(cwd)` → `defaultProjectTrust` 配置 → UI 交互，任一阶段返回即短路。
