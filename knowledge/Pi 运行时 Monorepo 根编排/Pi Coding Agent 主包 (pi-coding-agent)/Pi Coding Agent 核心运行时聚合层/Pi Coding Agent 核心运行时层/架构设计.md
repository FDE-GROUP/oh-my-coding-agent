本目录是 coding-agent 的进程内核心运行时，按职责拆分为多个子模块并通过 `sdk.ts` 中的 `createAgentSession` 统一装配：
- 启动编排：`sdk.ts` 解析 cwd/agentDir，创建 ModelRuntime（auth + models.json）、SettingsManager、SessionManager、DefaultResourceLoader，再构造 AgentSession。
- 生命周期分层：`agent-session.ts` 定义单会话状态机；`agent-session-runtime.ts` 管理多会话切换/分叉；`agent-session-services.ts` 暴露服务工厂供上层注入。
- 外部能力接入点：ExtensionRunner 在会话启动时加载 pi 扩展并注册自定义 ToolDefinition；MCP 服务器经 `mcp-servers.ts` 生成计划并入全局 mcp.json；Compaction 与 HTML Export 作为可选后处理管线挂载到会话事件。
- 共享基础设施：`event-bus.ts`、`http-dispatcher.ts`、`output-guard.ts`、`timings.ts`、`telemetry.ts` 被各子模块共同消费，构成跨子模块的横向支撑面。
- 配置驱动：所有可调行为（模型选择、工具白名单、thinkingLevel、transport、provider 重试、HTTP 超时、图像屏蔽）均经由 SettingsManager 读取，使 SDK 入口成为唯一配置汇聚点。
