- CLI 参数解析采用单例 `Args` 对象 + `diagnostics` 数组收集错误/警告，而非抛出异常，使 `parseArgs` 可返回部分结果供上层展示。
- 可选值型参数（如 `--mode`、`--tui-mode`、`--thinking`）通过常量白名单校验，非法值写入 `diagnostics` 中的 warning/error 条目而非中断解析。
- 未知 `--flag` 透传至 `unknownFlags: Map<string, boolean | string>`，由各子命令（如 `validateAuthCommandArgs`）自行判断是否接受。
- TUI 对话框统一遵循 create → addChild → setFocus → start → 回调中 stop + resolve 的生命周期模式，并通过 `settled` 守卫避免重复清理。
- 子命令通过枚举 `kind` + 专用 Error 子类（如 `AuthCommandError`）表达失败，用法字符串集中维护在 `*_USAGE` 常量中。
- 需要访问 SettingsManager 的 TUI 组件通过构造函数或 options 传入实例，而不是直接读取全局状态。
