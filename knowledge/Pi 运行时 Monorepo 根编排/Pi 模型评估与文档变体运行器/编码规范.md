- 评估用例文件统一命名为 `*.docs.eval.ts` 或 `*.eval.ts`，由 `vitest.evals.config.ts` 中的 project include 模式自动发现，而非显式注册。
- 对外暴露的 harness 函数采用 TypeScript overloads：无参返回 `Harness<PiCodingAgentInput, string>`，传入 `output` 时返回泛型输出类型，保持调用方类型推断。
- 所有外部命令（docker、文件系统、网络）均包裹 try/catch 并在 finally 中清理临时目录、恢复环境变量与 session，失败路径通过 `attachHarnessRunToError` 附加诊断信息。
- 敏感凭据通过 `InMemoryCredentialStore` 注入而非写入磁盘，sandbox 模式下还会把原始 env var 从进程环境删除后再恢复，避免泄露。
- 变体枚举（`DOCUMENTATION_VARIANTS`、`DocumentationVariant`）集中声明于 `plan.ts` 并以 `as const` 字面量数组派生类型，所有分支逻辑复用该枚举而非硬编码字符串。
