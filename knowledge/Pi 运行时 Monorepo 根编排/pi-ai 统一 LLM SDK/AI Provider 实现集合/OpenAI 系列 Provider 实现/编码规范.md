- Provider 通过调用 `createProvider` 工厂函数并以 `{ id, name, baseUrl, auth, models, api }` 对象字面量返回，区分官方 Responses API 与 legacy Codex 后端。
- OAuth 认证统一使用 `lazyOAuth` 包装 `loadOpenAIChatGPTOAuth` / `loadOpenAICodexOAuth`，并标注 `isSubscription: true` 以表明订阅型凭证。
- 模型清单集中放在独立的 `*.models.ts` 文件中，由 `catalog/generate.ts` 自动从 `data/*.json` 生成，禁止手动编辑。
- HTTP 客户端通过 `../api/*.lazy.ts` 懒加载导入（如 `openAIResponsesApi`、`openAIDecisionsApi`），避免启动期冷路径开销。
