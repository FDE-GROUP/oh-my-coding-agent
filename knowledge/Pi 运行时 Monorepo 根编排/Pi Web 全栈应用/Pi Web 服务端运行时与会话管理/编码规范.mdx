- 所有 server 模块导出均标注 `@internal` JSDoc，表明这些 API 仅供本模块内部与其他 server 文件使用。
- 类字段使用私有字段语法 `#field`，对外仅暴露 getter 或方法，避免直接暴露内部状态。
- API 路由统一通过 `createFileRoute(path)({ server: { handlers: { GET/POST/PATCH/DELETE } } })` 声明，并在 handler 开头调用 `getCurrentUser()` 获取当前用户。
- 对子进程命令调用采用 request-id + pending Map 的模式，配合超时定时器自动 reject 未响应的请求。
- 跨请求的全局单例（配置、运行管理器）通过挂载到 `globalThis` 上的命名属性实现懒初始化。
- 错误处理在路由层统一捕获 Error 实例并以 `{ error: message }` 形式返回，区分 400/404/500 状态码。
