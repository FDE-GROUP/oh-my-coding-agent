模块采用前后端同仓部署：`server.mjs` 作为唯一进程入口，先处理静态资源、登录页与 `/api/auth/*` 认证，再通过 `serverEntry.fetch` 将请求转发给 Vite 构建产物 `dist/server/server.js`（TanStack Start）提供的运行时；该运行时加载 `src/routes/api/*` 文件路由并调用 `src/server/*` 中的会话、工作区、运行时管理逻辑，最终把用户身份注入 `x-piweb-user` / `x-piweb-user-name` 响应头供后端使用。前端 `src/components/` 与 `src/lib/` 通过 `lib/api.ts` 调用同一套 `/api/*` 接口，共享 `shared_libs` 中的对话状态归约与图片工具。配置由顶层 `config.mjs` + `config.d.mts` 暴露，并通过 `PI_WEB_HOST` / `PI_WEB_PORT` 环境变量覆盖，非回环地址强制要求启用 `auth.users`。
