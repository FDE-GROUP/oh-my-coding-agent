## 面向 coding agent

本站随静态构建生成 agent 表面，不依赖服务端：

- `llms.txt` 与 `llms-full.txt`：站点索引与全文汇编。
- 每页的 `.md` / `.mdx` 镜像：在任意页面 URL 后加 `.md` 即得该页纯 Markdown 原文。
- JSON docs API 与 `.well-known/*` 清单：页面索引、导航、agent 技能发现。
