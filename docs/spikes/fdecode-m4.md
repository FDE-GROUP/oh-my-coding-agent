# Spike：FDE Code UI M4

> 对应 RAD：`docs/rads/fdecode-m4.md`；对应 issue：[#4](https://github.com/FDE-GROUP/oh-my-fde/issues/4)。
>
> 裁定：执行 M4-S1 到 M4-S3；分享必须登录、管理员默认只读、审计超过 10MB 轮转（2026-11-06）。
>
> 效力：证据与输入，不是编码依据。spike 代码在 `node_modules/.cache/fdecode-m4`，不进入 `main`。

## 1. 要回答的问题

| 编号 | 问题 |
|---|---|
| M4-S1 | 分享模型如何保证只读、可撤销、必须登录？token 如何存？ |
| M4-S2 | 交接文档能从 snapshot 提取哪些内容？改动文件和风险如何识别？ |
| M4-S3 | 审计追加并发是否可靠？查询与轮转是否可接受？管理员只读如何表达？ |

## 2. 环境与方法

| 项目 | 值 |
|---|---|
| 日期 | 2026-11-06 |
| Node | v22.23.0 |
| 会话 | 真实 RPC 子进程 + faux provider |
| 数据 | 临时工作区与会话，不使用真实模型 |

- S1：内存分享表 + 请求处理函数，模拟 owner/member/admin/未登录、过期、撤销、只读命令。
- S2：真实会话产生 `write` 工具调用，按 snapshot 生成 Markdown 交接文档。
- S3：审计追加 1000 条、查询尾部、10MB 轮转、权限检查。

## 3. 结果

### M4-S1 分享模型

| 检查 | 结果 |
|---|---|
| token 长度 | 32 字节随机，base64url 43 字符 |
| token 存储 | 只存 SHA-256，记录中不含明文 |
| 非所有者创建 | 403 |
| 未登录读取 | 401 |
| 成员读取 | 200，`readOnly: true` |
| 管理员读取 | 200 |
| 分享视图执行命令 | 403 |
| 错误 token | 404 |
| 非所有者撤销 | 无效果 |
| 所有者撤销后读取 | 404 |
| 过期后读取 | 404 |

结论：模型可行。只读分享应使用独立 token 和只读接口，不能复用命令端点。

### M4-S2 交接文档

| 检查 | 结果 |
|---|---|
| 是否包含目标 | 是 |
| 是否包含工具调用 | 是（`write`） |
| 是否识别改动文件 | 是（`src/import.ts`） |
| 是否包含风险与下一步 | 是（从“风险和下一步”小节提取） |
| 是否泄漏密钥 | 否 |
| 样例长度 | 338 字符 |

结论：snapshot 足够生成交接文档。改动文件从 `write`/`edit` 的 `path` 参数提取；风险按标题小节提取，比逐行关键词更准确。工具参数可能包含敏感内容，导出前需要模式脱敏。

### M4-S3 审计与管理员

| 检查 | 结果 |
|---|---|
| 1000 条追加 | 251ms，1000 行全部可解析 |
| 字段完整性 | 全部包含时间、用户、动作、目标、结果 |
| 尾部 20 条查询 | <1ms |
| 文件权限 | 0600 |
| 10MB 轮转 | 生成 `.1`，新文件为空 |
| admin 角色判断 | 可由配置字段直接派生 |

结论：单文件追加 + 写链 + 10MB 轮转足够 M4。管理员只读在 API 层通过“可读不可写”区分。

## 4. 结论与对 plan 的影响

| 编号 | 结论 | 影响 |
|---|---|---|
| S1 | 可行 | 新增分享存储、创建/撤销/列表 API、只读快照与 SSE、只读页面 |
| S2 | 可行 | 服务端生成 Markdown；导出按钮；脱敏规则 |
| S3 | 可行 | 审计模块、admin 角色、admin 列表与审计查询 |

### 被否决的选项

| 选项 | 理由 |
|---|---|
| 分享 token 明文存储 | 文件泄露即可冒用 |
| 未登录可看分享 | 超出团队内部边界 |
| 分享复用命令端点 | 只读无法保证 |
| 审计记录 prompt/工具输出 | 隐私风险且体积不可控 |
| 审计用数据库 | 当前规模不需要 |

### 风险

| 风险 | 应对 |
|---|---|
| 分享链接转发 | 必须登录、可过期、可撤销 |
| 交接文档泄漏参数中的密钥 | 导出前模式脱敏 |
| 审计文件无限增长 | 10MB 轮转，保留一份备份 |
| 管理员越权写 | 读写权限分离，命令端点仍校验 owner |

## 5. 对 plan 的具体建议

1. `shares.json` 0600 原子写；记录 token 哈希、session、owner、过期与撤销时间。
2. `/share/:token` 页面与 `/api/shares/:token/*` 只读接口；命令端点不暴露分享 token。
3. `/api/sessions/:id/handoff` 返回 `text/markdown` 附件；生成逻辑独立模块。
4. 审计 `audit.jsonl` 追加写 + 10MB 轮转；管理员 `/api/admin/audit`。
5. 配置用户增加 `role`；管理员可读全部会话但不可写；侧栏增加“全部会话”开关。
6. 分享页面隐藏 Composer、重命名、分叉、克隆等写操作。

## 6. 未决问题

- 分享默认有效期 7 天是否合适：plan 中可配置。
- 审计动作命名与保留字段：plan 中定表。
- 管理员是否需要导出交接：M4 允许只读查看，导出属所有者操作。
